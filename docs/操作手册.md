# 资料室管理系统操作手册

按左侧菜单对照阅读。无权限的菜单为灰色。先看右上角待办，再办理当前单据。界面按钮名、状态名与本手册一致。

## 入门与权限

### 登录与密码

1. 用分配的登录名和密码进入系统。
2. 管理员新开账号或重置密码后，登录窗会弹出 **请修改初始密码**。须先改密才能进主窗口。新密码至少 **8** 位，且不能与登录账号相同。
3. 日常改密：`系统设置` → `个人设置` → `修改密码`。须填当前密码、新密码、确认新密码；两次不一致或仍用账号当密码会提示失败。
4. 导航栏底部 **切换用户** 回登录窗；**退出系统** 关闭程序。

### 界面怎么用

- 登录后先到首页。右上角 **待办** 提示待审批、待交接、待上传签批单。
- 左侧菜单灰色 = 当前账号无权进入。
- 本页：`帮助` → `操作手册`，左侧点目录阅读。

> 部门侧用本部门资料管理员账号点「提交申请」；资料室侧用资料室账号点审批、交接、立档。系统管理员只做运维，不要代替点业务按钮。

### 角色分工（摘要）

权限由 **所属部门 + 用户角色** 一起决定，不是只看角色名称。开账号的完整对照见 `系统设置` 一章「业务权限」。

- **业务申请账号**：部门 ≠「资料室」，角色 =「部门资料管理员」→ 只能提交各类申请。
- **资料室办理账号**：部门 =「资料室」，角色 =「部门资料管理员」→ 审批、立档、盘库、离库、开柜等。
- **系统管理员账号**：角色 = `Administrator` 或「管理员」→ 用户/部门/角色、高级数据、业务逻辑、操作日志。**不能**维护服务器路径，也不能代替资料办理。
- **网管负责人账号**：角色 =「网管负责人」（部门不限）→ **仅**维护 `服务器路径设置`。不办理申请、审批、立档。

### 各业务审核与审批权限

> 系统里点「审批通过」的，一律是 **资料室办理账号**（部门「资料室」+ 角色「部门资料管理员」）。纸质单上的部门负责人、生产科、分管副院长等，由资料室在审批页填写姓名（或回填默认），再打印留白栏给对应职务**线下亲笔签**。领导不必用「院长」「部门负责人」角色登录来点按钮。系统管理员不能代替点审批。

办理顺序通例：申请人提交 → 资料室核对并录入签字人 → **审批通过** → 确认实物交接 → 上传签批扫描件 → 办结。盘库、立档、迁档、直办立档没有这一套审批。

#### 年度资料建档（申请审批）

菜单：`资料建档` → `申请审批`。仅资料室办理账号。

线下签完后，资料室在系统录入（只需签字人+日期，不填意见）：

1. **部门审核**（申请人所在科室部门负责人）
2. **生产管理科**（生产科负责人；纸质单要求其在各子项密级处手签密级和姓名）
3. **科研开发室**
4. **分管领导**（打印栏为「开发室分管领导」）
5. **资料交接**：移交人（申请人侧）+ **资料员**（资料室接收确认）

缺任一必填签字人不能点审批通过。通过后由资料室确认实物交接并上传签批交接单、资料照片。部门申请账号只能提交、撤回，不能打开审批页点通过。

#### 资料借出（审批出库）

菜单：`资料流转` → `审批出库`。仅资料室办理账号。四级审核审批均须完整才能通过：

1. **申请部门审核**（借出部门负责人）
2. **资料室负责人**
3. **生产科负责人**
4. **生产副院长**

通过后资料室办理实物交接、上传签批交接单与资料照片，再「资料出库办结」。部门账号只办「借出申请」。

#### 资料归还（审批入库）

菜单：`资料流转` → `审批入库`。仅资料室办理账号。按是否灭失分流：

- **完好归还**：签批交接单只需 **部门负责人**；系统审批区只录这一人，不展示资料室负责人及其他审批人。
- **存在灭失**：须借出时全部四级签字人均手签并录入：部门负责人、资料室负责人、生产科负责人、生产副院长。灭失说明必填。

通过后再确认实物交接（归还人、资料管理员、交接日期）并上传签批单后办结。指定归还目标盒也仅资料室可做。

#### 入网（入网审批）

菜单：`年度资料出入网管理` → `入网审批`。仅资料室办理账号。通过前须先按线下结果核实各明细密级，可补录服务器路径、资料路径和借出硬盘归位档口。

签字人（办结前须齐）：**部门负责人**、**生产管理科负责人**、**资料室负责人**、**分管领导**，以及交接栏 **移交人**、**资料员**。打印单对应「申请部门 / 生产管理科 / 资料室 / 分管领导 / 入网交接」。部门账号只办「入网申请」。

#### 出网（出网审批）

菜单：`出网审批`。仅资料室办理账号。通过后、确认交接前，须从离线介质补录电子目录与数据量。

签字人与入网相同：部门负责人、生产管理科负责人、资料室负责人、分管领导，以及移交人、资料员。打印单「分管领导」栏名可能随目的地显示为分管生产或分管资料副院长。部门账号只办「出网申请」。

#### 在网数据处置

菜单：`在网数据处置`。仅资料室办理账号（含新增、提交、审批、办结）。无部门「提交申请」侧。

审核 / 审批栏：**资料室负责人**（审核）、**分管资料副院长**（审批），仅签字与日期。点「审批通过」会自动填这两人姓名与日期，姓名可改。办结前须上传签批单。

#### 年度资料离库处置（模拟 / 电子）

菜单：`离库处置`。提交、审批、办结均资料室办理账号。

纸质签批：

- **审核**：资料室负责人、生产科负责人（签字+日期）
- **审批**：分管资料室副院长、分管生产副院长（签字+日期）

流程：提交 → 打印签批单线下签 → 审批通过 → 确认可上传 → 上传签批单（销毁另须处置资料照片）→ 办结。含低格留盘、撤柜时还须勾选确认。

#### 历史存档离库处置

菜单：`历史存档资料管理` → `资料离库处置`。仅资料室办理账号。

审核 / 审批：**资料室负责人**、**分管资料副院长**（姓名可改，日期只读）。三种处置方式办结前都须确认实物已撤柜；销毁另须处置照片。

#### 硬盘出库（出库审批）

菜单：`介质管理` → `硬盘` → `出库审批`。仅资料室办理账号。

系统录入 **审核人**（默认申请人所在部门负责人）、**审批人**（默认资料室负责人）。打印栏为「申请部门审核」「资料室负责人签批」。通过后确认实物交接、上传签批交接单、办结。部门账号只办「出库申请」。

#### 硬盘归还（审批入库）

菜单：`硬盘` → `审批入库`。仅资料室办理账号。

- **正常归还**：审核人（部门负责人）+ 审批通过 + 指定空白硬盘归位档口 + 交接办结。
- **损坏归还 / 挂失登记**：须填特殊情况说明并打印签批交接单；纸质还须归还人、申请人所属部门负责人、资料室负责人与资料室经办人签字。损坏须归损坏专用档口；挂失无需归位。

#### 硬盘离库处置

菜单：`硬盘` → `离库处置`。仅资料室办理账号。未挂在用资料袋的盘才能选。

系统「审批通过」记下当前办理人。打印「资料室审批」外，另有资料室负责人、资料室分管领导签字栏（线下签；办结后重打按办结日预填）。须上传签批单与硬盘照片后办结。已挂资料袋的硬盘改走「电子资料离库处置」，审批节点按年度资料离库。

#### 不走审核审批的业务

下列由对应权限账号直接办理，**没有**「审批通过」：

- 资料立档、存量硬盘/文本直办立档
- 模拟/电子迁档、开柜迁档
- 模拟/电子资料盘库、硬盘盘库登记（确认登记即办结）
- 项目信息维护、历史台账导入编辑、档案柜登记改用途
- 个人改密、系统设置中的运维项（服务器路径见下「网管负责人」）

网管负责人维护服务器路径也不走资料审批。

光盘无独立审批菜单，随资料出库/归还/盘库/离库走对应资料单。

## 待办、打印与签批

多数单据共用这套状态（列表筛选里能看到）：

1. `当前草稿-待提交`
2. `已提交-待审批`
3. `已审批-待实物交接`
4. `已实物交接-待上传签批交接单`
5. `已办结（业务已闭环）`
6. `已作废（撤回）` 或 `已作废（强制）`

办理节奏：`保存草稿 → 提交 → 审批通过 → 确认实物交接 → 上传签批扫描件 → 确认办结`。盘库类单据没有审批，确认登记即办结。

### 待办与个人设置

1. 右上角待办列出当前账号待处理事项。
2. `个人设置`：登录后显示待办弹窗、主界面显示待办角标、点击「知道了」后将当前待办标记为已读、待办刷新频率（秒）、待办展示条数。**保存设置** 生效，**恢复默认** 还原。
3. 未办结或未传必备附件时，角标会一直提示。

### 打印与附件

> 办结前打印：交接双方签字栏和日期栏留白。已办结后再打：才预填姓名和办结日期。

- 交接双方 = 当事人（申请人/领用人/归还人等）+ 资料室资料管理员。
- 部门审核、资料室负责人等非交接栏：审批完成后即可预填。
- 附件区常见分类：`签批交接单`、`资料照片`、`证明材料`、`其他附件`。每区一般支持 **上传** / **高影仪直拍**、**查看**、**删除**。格式多为 PDF 与常见图片。
- 申请时若「附有证明材料」选「是」，办结前必须上传证明材料扫描件。

### 卡在办结时先查

- 还没点过「确认实物交接」或「确认可上传」。
- 签批单未传；销毁类未传现场/资料照片。
- 声明有证明材料但附件区是空的。

记问题时写下：菜单路径、单号、当前角色、列表状态、期望与实际。

## 年度项目管理

菜单：`年度项目管理` → `项目信息设置`。

维护项目名称、项目编号、实施年度、资金管理部门、备注。建档、立档台账、出入网都会引用。

**权限：** 仅资料室资料管理员可新增、编辑、删除；其他人仅可浏览与检索（否则提示「仅资料室资料管理员可编辑项目信息。」）。

建议先有项目再建档。存量直办页可用 **查看年度已有项目**；也可手输尚未登记的年度/项目名，选中已有项目时会带回编号。

## 资料建档与立档

菜单：`年度资料档案化管理` → `资料建档`。

正规路径：**建档申请 → 申请审批（交接办结）→ 资料立档**。模拟入档案盒再入档口；电子入介质袋（硬盘/光盘）再入磁盘柜。

### 建档申请（部门）

菜单：`建档申请`。列表标题「资料登记申请办理表」。

**列表：** `新增申请`、`打开申请`、`撤回申请`、`刷新列表`。可按状态、申请年度筛选（「全部」含未提交）。

**表单必填：** `资料名称 *`、`所属项目 *`、`资料来源 *`、`提供单位 *`、`归档目的 *`、`申请人 *`、`部门 *`、`日期 *`。至少维护一组 **资料介质（电子）** 或 **资料介质（模拟）**。

1. `+ 添加资料子项`。模拟可改份数；电子份数通常为 1。子项含名称、密级等。
2. 电子行内 **借出硬盘**：是/否。为「是」时填借出硬盘编号（当前登记人名下未还的盘）。也可 **使用库内空盘** → **选择**。再填 **硬盘是否归还** 及预计归还日期。
3. **附有证明材料** 为「是」时填名称；扫描件由资料室在审批环节上传。
4. 按钮：`保存草稿` → 核对后 `提交申请`（提交后审批信息重置，状态变为「已提交-待审批」）→ 需要纸质时 `打印申请`。
5. 未提交或按规定可撤阶段用列表 **撤回申请**。提交后部门侧不能再改内容。

### 申请审批与交接（资料室）

菜单：`申请审批`。列表「资料登记审批办理表」：`打开审批`、`强制作废`、`刷新列表`。

审批节点（仅签字人+日期，不填意见）：`部门审核` → `生产管理科` → `科研开发室` → `分管领导` → `资料交接`（移交人 + 资料员）。

**办理顺序：**

1. 打开「已提交-待审批」单，按线下结果核实各子项密级。
2. `审批通过` → 状态「已审批-待实物交接」。
3. 申请人携带资料和打印单到资料室，点 `确认实物交接`。
4. 附件区上传签批交接单、资料照片（必传）；申请声明有证明材料则再传证明材料。
5. `确认办结` → `打印交接单`（此时可出带预填签字的存档副本）。

> 办结只表示申请闭环，资料还没落到柜里。接着打开 `资料立档`。

出网办结若生成建档草稿，在建档列表里继续补全，不要当全新申请重填。

### 资料立档（资料室）

菜单：`资料立档`。页签：`模拟介质立档`、`电子介质立档`（显示待办/已办计数）。

**模拟介质立档**

1. 左侧待立档池：按年度筛选、`刷新`；Ctrl/Shift 可多选同一项目。
2. 第一步看登记信息（项目、归属年度只读）。
3. 在资料子项列表勾选**本次拟入盒**内容，可分多次立完。
4. 立档方式：`新建档案盒` 或 `并入选中档案盒`（当年已有盒）。
5. 新建时填/选 `档口编号`，用 `建议档口位置`、`档口占用快照`。并档时不必再选新物理位置。
6. 赋码：`档案盒编号` 可 `自动生成`，核对规格、格内现有盒数、备注。
7. 点 `执行模拟介质立档`。标准滑道柜只能落入「年度资料专用档口」或「混用档口」。

**电子介质立档**

1. 左侧待立档池；每次只办一个电子介质条目。「已全部立档」的不再重复立。
2. 选介质表单后带出该介质下全部明细，不能拆开只立一部分。
3. 立档方式（按页选项）：`选择一块空硬盘，立档`、`使用该硬盘直接立档`、`使用1张光盘，立档`、`数据并入本项目已立档硬盘`。拷贝新建时 `选择库内空盘`。
4. 「立档存储路径」可改（浅黄底）；拷贝型常预填 `\年度\项目\资料名称\子项名称_001\`。
5. 外来硬盘按向导 `登记外来硬盘`；空盘用 `空白硬盘入库推荐档口`。
6. 物理位置：`建议档口位置`、`档口占用快照`。并档可跳过选新位置。
7. 赋码后点 `执行电子介质立档`。推荐年度数据硬盘/光盘专用档口空位（含档内序号）。

完成后到 `立档台账` 核对立档编号、盒/袋号、柜位、生命周期。

> 同一档口 = 柜号 + 柜面 + 层号 + 列号。盒序号、硬盘档内序号只是格内占位。

### 存量硬盘资料直办立档

菜单：`存量硬盘资料直办立档`。资料室直接登记并电子立档，**无需申请审批**。根目录必须是 `年度/项目/资料名称/子项/…`，一块盘只允许一个年度/项目。

1. **硬盘参数：** `生成编号`、`读取本机`（序列号/品牌/容量等）。
2. **目录扫描：** `选择目录` → `扫描`；填实施年度、项目；`查看年度已有项目`。
3. **立档默认值与档口：** 来源固定「存量直办」、提供单位「资料室」；`数据档口` 用 `推荐空位`、`档口快照`。
4. **扫描预览：** 资料名称、子项、组织形式、数据量、立档路径。
5. `确认立档`。确认前编号仅为预览、不占号。同年度/项目已有袋时仍新建第二袋。

### 存档文本资料直办立档

菜单：`存档文本资料直办立档`。按盒登记纸基模拟资料，直接建档+模拟立档。载体如打印纸、绘图纸、打印相纸、感光胶片/相纸。

1. **年度/项目** → **立档默认值**（资料名称、来源、提供单位、库管模式）。
2. **资料介质（模拟）*：** `+ 添加资料介质` → `+ 添加资料子项`（名称、份数、资料类型、所属子类、组织形式、密级）。
3. **档案盒与落位：** 预览盒号；`资料档口` 用 `刷新档口`、`推荐空位`、`档口快照`。
4. 手工一次只确认 1 个新盒。或点 `从 Excel 导入`。
5. `确认立档`。

**Excel：** 先选工作表。必要列表头：`年度`、`项目名称`、`资料名称`、`子项名称`、`份数`、`档案盒编号`、`档案盒规格`。年度须四位。按表内物理盒号导入，不改推荐档口。可勾选按「子项名称」单元格分行拆多条子项。预览「可导入/不可导入」；点 `导入可立档盒`；失败盒不阻断后续盒。

## 资料检索

菜单：`年度资料档案化管理` → `资料检索`。

> 检索勾选 → 加入筛选池 → 保存为结果集（可选）→ 在检索池点发起借出或入网。不要在库外零散记编号。

### 三种检索页

- `资料检索(综合模式)`：关键词可查资料名称、单号、申请人、项目、提供单位。`查询` / `重置`。结果含登记状态、立档状态、盒/袋号、物理位置。`查看` 打开详情。
- `电子介质资料检索` / `模拟介质资料检索`：条件含表单号、项目、资料名、库管模式、子项、目录/文件名（支持 `*` `?`）。

### 筛选池与结果集

检索页：`选中加入筛选池`、`本页全部加入`；池内 `移出选中`、`清空筛选池`。内容区 `全部选择` / `清空选择` / `切换选择`。

`保存筛选池为结果集`：须填名称；可校验份数；带「借出中」提示时仍允许保存。

### 检索池页

菜单：`检索池`。切换电子/模拟介质池；可勾 `仅看我创建的`；状态 `草稿` / `已确认`。

- `查看资料`、`移出选中条目`、`保存修改`。
- `发起借出申请`：有选中行则只带选中行，否则整池。
- `发起入网申请`：规则同上；电子池可生成存档资料入网草稿。

一般人只能管本人创建的池；资料室可看全部。已借出、盘库异常、已离库的条目会有提示，不能当正常在库去领。份数上限不超过立档份数。

## 资料借还

菜单：`年度资料档案化管理` → `资料流转`。状态与建档类似；归还在上传签批后还可能显示「已上传签批交接单-待办结」。

### 借出申请（部门）

菜单：`借出申请`。列表新建/打开/作废 + 状态筛选 + `刷新列表`。

1. 填 `申请原由 *`。`资料去向`：`本部门（内部）` 或 `外部（单位）`（外部须填单位）。
2. `通过检索集登记拟领用的资料` 引入盒/袋明细。
3. 按盒/袋统一设 **领用方式**：模拟 `提档` / `复制`；电子 `提档` / `拷贝`。长期存档电子介质仅支持拷贝，原件留库。
4. **提档** 校验拟提份数 ≤ 可借份数，办结后扣库存（需归还则产生待还）。**复制/拷贝** 不扣库内份数。
5. 提档时按提示选择是否归还；拷贝可选择目标空盘及硬盘是否归还。
6. `保存草稿` → `提交申请`；可 `打印`、按规定 `撤回`。

### 审批出库（资料室）

菜单：`审批出库`。`打开办理`。

签字节点：`部门审核` → `资料室负责人` → `生产科负责人` → `生产副院长`。

顺序：`审批通过` → `确认实物交接`（填领用人等）→ `打印审批单` / `打印交接单`（办结前签字留白）→ 可用 `业务助手` 核对 → 上传 `签批交接单`、`资料照片`（必传）及声明的证明材料 → `资料出库办结`。

办结后提档资料变为借出/部分可借；电子提档同步硬盘或光盘台账。不需归还的提档可能导致空盒按业务规则自动释档（与盘库致空不同）。

### 归还申请 / 审批入库

菜单：`归还申请`、`审批入库`。侧重模拟介质提档原件收回。左侧常见 `待归还出库单` 与 `归还单`。

1. 在待还出库单上 `查看借出详情`、`发起归还`。
2. 明细填 `完好归还份数` + `灭失份数`（与借出份数对应）；有灭失填 `灭失说明`。
3. 原盒失效时 `指定目标盒`（选在用档案盒作为入库目标）。新开空盒只能落入年度专用或混用档口。
4. 申请侧：`保存草稿`、`提交申请`、`打印签批交接单`、`撤回作废`。
5. 审批入库：完好归还签 `部门负责人` 后 `审批通过`；有灭失须借出时全部审核审批人（部门/资料室/生产科/生产副院长）再通过。然后 `确认实物交接`（归还人、资料管理员、交接日期）→ 上传签批交接单 → `确认办结`（冲销台账并归位）。另有 `打印交接单`、`强制作废`。

灭失计入出库灭失，不要和盘库丢失混填。`流转台账`、`跨域流转台账` 只查询，不能改状态。

## 资料迁档

仅资料室。目标用途须匹配：年度模拟 → 年度专用或混用；电子袋 → 对应数据硬盘/光盘专用档口。完成后到 `迁档台账` 核对迁前迁后位置。

### 菜单：模拟介质资料迁档

迁档模式：`物理位置迁移` / `并入已有档案盒`。

1. 选源档案盒与关联资料。
2. 目标可选档口（A/B 面），用 `档口占用快照`。可勾选「迁入空盒（目标档口新建盒，源盒销号）」并选新盒规格，或选目标已有盒。
3. `生成预览` → `确认迁档`。

### 菜单：电子介质资料迁档

迁档模式：`物理位置迁移` / `迁入空盘/空袋` / `并入同项目硬盘`。

1. 指定目标档口、`空盘选择` 或目标电子袋。
2. 可选「保留原件，执行备份机制」。并档后按提示确认原盘已格式化按空盘管理，或原光盘已销毁。
3. `生成预览` → `确认迁档`。

### 开柜现场迁档

菜单：`档案柜管理` → `档案柜登记`，打开柜体。标准模式可拖拽；**紫高亮=可放，红高亮=不可放**。

**点选：** 单击选中；Ctrl 同档口多选同类型；Shift 范围选。工具栏或右键 `设为迁档对象`，到目标档口 `迁档到此档口`（或拖放），确认「确认执行迁档？」。档案盒多选仅限同档口。电子袋标「X」（损坏载体）仍可迁袋；标「失」「销」不能当源。损坏硬盘/光盘在专用档口内用开柜挪口。

**整档口：** 源档口右键「设为批量搬迁源」→ 同柜/跨柜/跨面打开目标，右键「搬迁到此档口」→ 预览后执行。目标一般须全空（空白/损坏专用档口按剩余盘位，允许非全空）。混放档口不能当搬迁源。迁出后余下实体保持原序号。

本会话有成功迁档时，须先打印「本次开柜迁档汇总清单」并确认线下核对后才能关窗。

## 盘库与离库

仅资料室。先盘库记中间态，再离库清账。盘库确认即生效，没有签批。

> 盘库导致的空盒/空袋仍占档口，开柜标「失」「销」，不标「空」。出库不还或归还灭失造成的业务空盒才会自动释档。

### 模拟资料盘库 / 电子资料盘库

菜单：`盘库登记`。列表「模拟资料盘库登记办理表」/「电子资料盘库登记办理表」。`新增登记`、`打开办理`、`撤回作废`；按状态、年度、关键词 `查询` / `刷新`。

弹窗：`保存草稿`、`确认登记办结`、`撤回作废`。确认语：「办结后即时写入台账，不可再改。」

- **模拟登记类型：** `盘失登记`、`拟销登记`（无存档价值）。用 **加入 → / ← 移除** 从左侧（可按档口筛选）挑选子项。盘失须填丢失份数且不超过可用份数；拟销时丢失份数列只读。出库待还大于 0 时不能拟销；拟销须整批等于当时库内份数。
- **电子登记类型：** `盘失登记`、`损坏登记`、`拟销登记`。对象是袋内硬盘/光盘，不是袋子本身。办结改介质台账但保留档口与介质袋，关联资料不可再借出。损坏改档口请走开柜迁到损坏专用档口，不要在盘库里挪口。

登记说明可空（默认用当前登记类型）。同一介质不能同时挂未办结的资料盘库、硬盘盘库、硬盘离库、资料离库。

### 模拟 / 电子资料离库处置

菜单：`离库处置`。只清盘库产生的失/销/损坏。列表 `新增处置`、`打开办理`、`撤回作废`。单号类似「资离-处」。

弹窗按钮顺序：`保存草稿` → `提交` → `打印签批单` → `审批通过` → `确认可上传` → 上传附件 → `办结`（旁路 `撤回作废`）。须先「确认可上传」再传附件。

明细：`移入 ▶ / ◀ 移出`；勾选同原因后选方式再点 **赋值**。

| 情况 | 允许处置方式 |
| --- | --- |
| 模拟盘失 | 库内注销 |
| 模拟拟销 | 离库销毁 |
| 电子盘失 | 库内注销 |
| 电子损坏 | 离库销毁 |
| 电子光盘拟销 | 离库销毁 |
| 电子硬盘拟销 | 低格留盘（默认）或离库销毁 |

- **低格留盘：** 列「空盘档口」，`推荐` / `快照`。办结前填写目标空白硬盘档口（不预占）。办结勾选 **已确认硬盘低级格式化**。
- 将释档空盒/空袋时勾选 **已确认空盒/空袋物理移除**。
- 附件：`签批单` 必传；`离库销毁` 还须 `处置资料照片`。列表可看已传签批单、已传照片。

已挂在用资料袋的硬盘不要走「介质管理 → 硬盘 → 离库处置」，应走本页电子离库。

## 出入网

菜单：`年度资料出入网管理`。部门申请，资料室审批。

### 入网申请 / 入网审批

列表 `新增入网`、`打开办理`、`撤回作废`。

**数据来源 *：** `存档资料` / `档外资料（院内）` / `档外资料（院外）`。

- 存档：明细来自电子资料检索结果集（从检索池 `发起入网申请` 最顺）；提供部门固定为资料室。
- 档外院内：提供部门下拉院内部门。档外院外：提供部门手填。档外用「+ 添加资料介质（电子）」录入明细。

整单共用 **服务器路径**、**资料路径**。可用 **填入默认资料路径**（规范：申请部门\入网\年度\项目\资料名称）。路径目录由 **网管负责人** 在 `系统设置` → `服务器路径设置` 维护。

申请：`保存草稿` / `提交申请` / `打印申请`。证明材料选「是」须填名称。

审批顺序：核实明细密级 → `审批通过`（可 `回填默认审批信息`；通过前资料员可补录路径）→ `确认实物交接` → 上传签批交接单（及证明材料）→ `确认办结` → `打印交接单`。办结写入 **在网台账**。

若勾选入网时归还借用硬盘：审批区「借出硬盘归位」为每块盘指定空白硬盘档口（`推荐档口` / `档口快照`）。

### 出网申请 / 出网审批

列表 `新增出网`。**目的地：** `出网（院内）` / `出网（院外）` / `资料室存档`。

- 生产网填 **服务器路径** + **出网资料所在具体路径**（选路径并完善年度/项目/资料名称后可按规范生成）。
- 目的地为资料室存档时须选 **库管模式 ***；办结后生成 **待立档任务**（目标建档表单编号），归档载体到 `资料立档` 再选。电子介质锁定「内网 + 无需处置」。
- 院内/院外离线允许光盘/硬盘/U 盘等。审批通过后、确认实物交接前，从离线介质补录电子介质目录与数据量。

申请必填：`申请说明 *`、`申请人 *`、`部门 *`、`日期 *`。按钮同入网：保存草稿、提交、打印。审批：`审批通过` → `确认实物交接` → `确认办结` → `打印交接单`。跨域过程可在 `跨域流转台账` 查看。

### 在网数据处置

列表 `新增处置`、`打开处置`、`撤回作废`；另有 `查询台账`、`查看详情`、`查询单据`。

处置原因：`到期清理` / `中间成果删除` / `软件卸载` / `安全销毁` / `其他`。处置方式：`服务器删除` / `台账注销` / `其他`。

候选区：`刷新候选`、`查看详情`、`加入明细`、`赋值`。按钮：`保存草稿` → `提交` → `打印签批单` → `审批通过`（自动填资料室负责人、分管资料副院长，姓名可改）→ `确认可上传` → 上传签批单 → `办结`。

办结前不要只在服务器上删目录而不走本单。本流程无低格留盘、无撤柜勾选。

## 历史存档

菜单：`历史存档资料管理`。与年度立档事实分开，按盒号管理。

### 地形图 / 航摄胶片像片 / 其他资料

按钮：`导入Excel表`、`浏览数据`、`编辑`、`检索`、`重置`、`导出`、`删除当前行`、`删除表`。浏览：`分页浏览` / `全局浏览`，分页首页/上一页/下一页/末页。

- 资料室可导入、编辑、删除。其他部门资料管理员仅浏览与检索（否则提示「仅资料室资料管理员可录入或编辑历史存档资料。」）。
- 默认不显示已离库；勾选 **含已离库** 才看。已离库不能再改盒号。
- 检索条件因页而异（地形图：盒号、比例尺、图号；航片：测区、摄影日期；其他：序号、资料分类等）。
- 历史盒落入「历史资料专用档口」或「混用档口」。Excel 导入：未设置且无年度占用 → 同步为历史专用；已有年度盒或已是年度专用 → 改为混用。

### 资料离库处置

仅资料室。列表 `新增处置`、`打开处置`、`撤回作废`；`查询盒`、`查询单据`。单号类似「史离-处」。

> 一单仅一类资料、一种处置方式；混放盒须整组纳入或整组移除。跨类同盒须先拆盒。

资料类别：`地形图图件` / `航摄胶片、像片` / `其他资料`（选定后不可改）。处置方式：`离库销毁` / `离库转交` / `其他`。转交须填转交对象；其他须填说明。

候选：`刷新候选`、`加入明细`、`全部加入明细`、`清空明细`。按钮同七态：保存草稿 → 提交 → 打印签批单 → 审批通过（资料室负责人、分管资料副院长）→ 确认可上传 → 办结。

办结确认：「对应档案盒已从档案柜撤出实物。」成功后台账标已离库并撤盒，台账行保留备查。销毁须处置资料照片；三种方式都要确认实物撤柜。

## 档案柜

菜单：`档案柜管理`。

- `档案柜登记`：`新增柜子`、`编辑选中`、`删除选中`、`刷新`。仅资料室（否则「仅资料室资料管理员可办理档案柜登记。」）。
- `档案柜检索`：`打开柜体 A 面` / `B 面`、`刷新`。其他人可浏览开柜查看，不能改柜。

### 开柜

工具栏：`全选`、`反选`、`设置用途`、`清空选择`；可选 `设为迁档对象`。显示 **标准 / 简洁**。单击选中，Ctrl/Shift 多选，双击或右键看详情。多选后可统一设置用途。空档口才能改用途。

**标准滑道柜用途：** 未定义（未设置）/ 年度资料专用档口 / 历史资料专用档口 / 混用档口。立档、归还新开盒、年度迁档会按用途拦截。

**防磁磁盘柜用途（开柜里设，启动不会冲掉已保存项）：** 空白硬盘专用、年度/历史数据硬盘或光盘专用、损坏硬盘/光盘专用等。未配置过的格口启动时默认补空白硬盘专用档口。

档案盒放置：`盒脊向外` / `盒面向外`。双击可看盒/袋内容。角标概要：右上失/销为盘库异常（不标空）；右下待还；左下预订；左上混放等。空白盘位置只到档口，数据盘带档内序号。

先规划面数、层数、列数再保存。有占用时不要随意缩小柜体。柜名会写入盒位和硬盘位置，改名要谨慎。

## 硬盘与光盘

### 硬盘

菜单：`介质管理` → `硬盘`。部门只发起出库/归还；盘库、离库、改档口是资料室。`概览` 看 KPI（待审批、待交接、待上传、待办结等），可点进下钻。

**初始登记：** `批量式登记` / `交互式登记` / `硬盘参数修正` / `注销所选硬盘`；可查询、导出台账、刷新。弹窗 `生成编号`、`读取本机`、`推荐档口`、`档口快照`。此处只维护基础参数，状态由台账维护。空白盘落入空白硬盘专用档口（无档内序号）。

**出库申请 / 出库审批：** 类型 `出库(临时)申请`（约 1 个月、可填预计归还日）、`出库(长期)申请`（不设期限）、`出库(永久)申请`（另有他用、无需归还）。审批五步：`审批通过` → `确认实物交接` → `上传签批交接单` → `确认办结` → `打印交接单`。征用库内空盘会加锁。

**归还申请 / 审批入库：** 待还介质上 `发起归还`。登记类型 *：`正常归还`（归空白硬盘专用档口）、`损坏归还`（归损坏专用档口）、`挂失登记`（无需归位）。非正常归还须填特殊情况说明并打印签批交接单。再确认实物交接、确认办结；必要时强制作废。

**盘库登记：** 类型 `损坏登记` / `盘失登记`。仅「在库(空盘)」「在库(损坏)」可选。损坏须指定损坏硬盘专用档口（推荐/预览）；盘失清空档口。`确认登记办结` 即时写台账，无需审批。正式离库走下一菜单。

**离库处置：** 候选为在库空盘/损坏/盘失/拟销，且未挂在用资料袋。流程：草稿 → 提交 → 打印 → 审批 → 确认可上传 → 上传签批与硬盘照片 → 办结。已挂资料袋的走电子资料离库。

**硬盘台账：** 查状态、位置、流转流水（进出资料室、换档口、同档口改序号）。

### 光盘

菜单：`光盘` → `概览`、`流转台账`。光盘随电子立档自动产生，**不管理空白盘**，无独立借还。点 KPI 下钻台账。办理走年度资料出库/归还/盘库/离库。拟销或损坏离库后常为出库(销毁)；盘失走库内注销。不能单独出库或格式化留盘（那是硬盘的能力）。

## 系统设置

除「个人设置」外：系统管理员可进用户/部门/角色、高级数据、业务逻辑、操作日志；**服务器路径设置仅网管负责人可进**（否则提示「仅网管负责人可维护服务器路径设置。」）。资料办理人不要用系统管理员或网管账号去点建档、审批、立档。

### 用户、部门、角色怎么开

顺序：**先部门、再角色、再用户**。用户上的「所属部门」「用户角色」必须与部门表、角色表中的名称完全一致（不要多空格、不要改用近义名）。

1. `部门设置`：院内部室名称。资料室办理人依赖的部门名必须是 **资料室** 三个字。
2. `角色设置`：业务相关角色至少包括 `Administrator`（或「管理员」）、**部门资料管理员**、**网管负责人**。其余如「部门负责人」「分管资料副院长」等主要用于单据签字栏人选，**单独配这些角色登录，并不能获得申请或审批菜单**。
3. `用户管理`：登录名、真实姓名、所属部门、用户角色、初始密码。新增密码必填（≥8 位、不能等于登录名）。编辑时密码留空表示不改。重置后对方下次登录必须自己改密。

> 判定规则只认账号上的部门、角色字段，不按真实姓名是否「资料员」推断。一人多岗请开两个账号，分别配部门+角色，不要把系统管理员角色和资料办理角色混在一个账号上指望「全能」。

### 业务权限：先看部门，再看角色

系统把登录用户分成四类业务身份。下表是**推荐配法**。

| 业务身份 | 所属部门 | 用户角色 | 用来做什么 |
| --- | --- | --- | --- |
| 部门申请经办 | 任一业务科室（航测外业室、地理信息室、生产管理科等），**不能是「资料室」** | `部门资料管理员` | 只发起申请：建档、借出、归还、入网、出网、硬盘出库/归还 |
| 资料室办理 | **必须是「资料室」** | **必须是「部门资料管理员」** | 审批、交接、立档、直办立档、迁档、盘库、离库、档案柜登记、历史录入、硬盘入库/审批/盘库/离库 |
| 网管 | 任意（种子账号常在科研开发室） | **必须是「网管负责人」** | **仅** `服务器路径设置`（增删改路径名称、物理地址、权限、容量） |
| 系统运维 | 任意 | `Administrator` 或 `管理员` | 用户/部门/角色、高级数据、业务逻辑、操作日志；**不含**服务器路径 |

同一角色名「部门资料管理员」配到不同部门，权限完全不同：在生产科室是**申请人**，在资料室是**办理人**。资料室账号**不能**再点「提交申请」，避免自己审自己。

**不要这样开：**

- 部门选「资料室」，角色却选「部门负责人」→ 既不能申请，立档/硬盘登记等菜单也常是灰色（资料室负责人签字由办理人在单据上填写姓名，不必用负责人账号登录办理）。
- 部门选生产科室，角色选「部门资料管理员」，却指望能点「申请审批」「资料立档」→ 菜单灰色。
- 只把角色改成「资料室资料管理员」「资料室管理员」，部门也是「资料室」→ 部分审批/迁档能办，但 **资料立档、直办立档、立档/迁档/流转台账、硬盘初始登记与出库审批/盘库/离库** 仍可能灰色。资料室办理请统一用角色「部门资料管理员」。
- 用 `Administrator` 登录去立档、审批 → 系统管理员**不替代**资料室/部门资料管理员，业务按钮仍无权限。
- 用 `Administrator` 去改服务器路径 → 菜单灰色，提示仅网管负责人可维护。路径须用角色「网管负责人」的账号。
- 网管负责人账号不能提交出入网申请或审批；出入网单里只是**选用**已维护的路径。

### 按菜单：谁能进、谁能改

灰色 = 当前账号无权进入。能打开页面不等于能改数据。

**所有登录用户（含负责人、院长等非经办角色）通常仍可：**

- `帮助` → `操作手册`；`系统设置` → `个人设置`（改自己的密码和待办偏好）
- `年度项目管理` → `项目信息设置`：**浏览、检索**；增删改仅资料室办理账号
- 三种资料检索、检索池（一般人只能管**自己创建**的池；资料室办理账号可看全部）
- 历史三录入页：**浏览、检索、导出**；导入/编辑/删除仅资料室办理账号
- `档案柜检索`：开柜查看；不能改布局、用途、摆放
- 硬盘 `概览`、`硬盘台账`；光盘 `概览`、`流转台账`

**部门申请经办（科室 + 部门资料管理员）可点、资料室办理账号反而不能点的申请菜单：**

- 建档申请；借出申请；归还申请；入网申请；出网申请
- 硬盘出库申请、硬盘归还申请

列表里一般只办本账号提交的单；保存草稿、提交、撤回申请都是申请人侧。不能点申请审批、立档、迁档、盘库、出入网审批、在网处置、档案柜登记、硬盘初始登记/出库审批/盘库/离库。

**资料室办理（资料室 + 部门资料管理员）可点：**

- 申请审批、资料立档、存量硬盘/文本直办立档、立档台账、迁档台账、流转台账、跨域流转台账
- 审批出库、审批入库；模拟/电子迁档；模拟/电子盘库
- 入网审批、出网审批、在网数据处置；历史资料离库处置；档案柜登记
- 硬盘初始登记、出库审批、审批入库、盘库登记、离库处置
- 项目信息、历史台账的导入编辑删除；开柜改用途、迁档、摆放

模拟/电子资料离库、历史离库：无权限账号即使能点开，办理时仍会提示仅资料室可办。

**网管负责人可点：**

- `系统设置` → `服务器路径设置`（新增、编辑、删除）。个人设置与帮助、检索浏览等同其他登录用户。
- 不能提交申请、不能审批立档、不能进用户管理和高级数据管理。

**系统运维（Administrator / 管理员）可点：**

- 用户管理、部门设置、角色设置、高级数据管理、业务逻辑设置、数据库操作日志
- 不能维护服务器路径，也不能当作「超级资料员」去提交申请或审批立档

### 签字角色与登录权限不是一回事

角色表里的「部门负责人」「分管生产副院长」「分管资料副院长」「院长」等，对应打印单、审批栏上的**职务名称**。资料室办理人在审批页填写这些姓名（或回填默认），并不要求院长本人用「院长」角色登录来点「审批通过」。

「网管负责人」**不是**签字栏职务，而是登录后维护服务器路径的业务角色，须单独开账号。

给领导单独开登录账号时：若不兼办申请，角色不要选「部门资料管理员」，菜单会以查询、浏览为主，避免误提交。

### 服务器路径

**仅网管负责人**可进入 `系统设置` → `服务器路径设置` 做增删改。系统管理员、资料室、部门资料管理员都不能改路径目录，只能在出入网单据里选用已登记路径。

维护项：部门（含公用）、路径名称、物理地址、权限、容量。改物理路径前确认没有进行中的入网/出网单还在用旧地址。角色名必须与角色表完全一致：`网管负责人`。

### 业务逻辑设置

申请单逾期等。改完影响未办结单据的提醒，不要频繁改。

### 个人设置

任何登录用户：`修改密码`、待办弹窗/角标/「知道了」标已读、刷新秒数、展示条数。`保存设置` / `恢复默认`。

### 高级数据管理

`备份当前库` / `从备份还原`。共享库时先让其他终端退出。覆盖安装只替换程序文件，不要覆盖 `DocMgr.db`。还原会覆盖当前库且不可撤销，完成后程序退出，须重新打开。详见「安装与升级」。

### 数据库操作日志

按时间、用户、表名查看增删改摘要，用于事后核对，不是办理入口。
