# 资料室管理系统操作手册

按左侧菜单对照阅读。无权限的菜单为灰色。先看右上角待办，再办理当前单据。界面按钮名、状态名与本手册一致。

## 入门与权限

### 登录与密码

1. 用分配的登录名和密码进入系统（登录窗标题为「测绘资料管理系统 · 用户登录」）。
2. 首次部署或管理员重置密码后，登录会弹出 **请修改初始密码**，须先改密才能进主窗口（取消则提示「必须修改初始密码后才能进入系统。」）。新密码至少 **8** 位，且不能与登录账号相同。
3. 日常改密：`系统设置` → `个人设置` → `修改密码`。须填当前密码、新密码、确认新密码；两次不一致或仍用账号当密码会提示失败。
4. 导航栏底部 **切换用户** 回登录窗；**退出系统** 关闭程序。
5. 同一账号在第二台终端登录时会提示单点登录，可选择强制顶替。

### 界面怎么用

- 登录后先到首页：看右上角 **待办角标**（审批、交接、签批上传未完成时持续提示），再按角色进入左侧菜单。
- 左侧菜单按模块折叠展开：年度项目管理、年度资料档案化管理、年度资料出入网管理、历史存档资料管理、档案柜管理、介质管理、系统设置、帮助。灰色 = 当前账号无权进入。
- 顶部有 `返回上级页面`、`返回首页`；右上角 `待办`、`切换用户`、`退出系统`。
- 本手册：`帮助` → `操作手册`，左侧目录点章节阅读；页面还显示当前版本号与数据库路径（本地库/共享库）。

> 部门侧用本部门资料管理员账号点「提交申请」；资料室侧用资料室账号点审批、交接、立档。系统管理员只做运维，不要代替点业务按钮。

### 角色分工（摘要）

权限由 **所属部门 + 用户角色** 一起决定，不是只看角色名称。开账号的完整对照见 `系统设置` 一章「业务权限」。

- **业务申请账号**：部门 ≠「资料室」，角色 =「部门资料管理员」→ 只能提交各类申请。
- **资料室办理账号**：部门 =「资料室」，角色 =「部门资料管理员」→ 审批、立档、盘库、离库、开柜等。
- **系统管理员账号**：角色 = `Administrator` 或「管理员」→ 用户/部门/角色、高级数据、业务逻辑、操作日志。**不能**维护服务器路径，也不能代替资料办理。
- **网管负责人账号**：角色 =「网管负责人」（部门不限）→ **仅**维护 `服务器路径设置`。不办理申请、审批、立档。

### 各业务审核与审批权限

> 系统里点「审批通过」的，一律是 **资料室办理账号**（部门「资料室」+ 角色「部门资料管理员」）。纸质单上的部门负责人、生产科、分管副院长等，由资料室在审批页填写姓名（或回填默认），再打印留白栏给对应职务**线下亲笔签**。领导不必用「院长」「部门负责人」角色登录来点按钮。系统管理员不能代替点审批。

办理顺序通例：申请人提交 → 资料室核对并录入签字人 → **审批通过** → 确认实物交接 → 上传签批扫描件 → 办结。盘库、立档、迁档、直办立档没有这一套审批。

### 年度资料建档（申请审批）

菜单：`资料建档` → `申请审批`。仅资料室办理账号。

线下签完后，资料室在系统录入（只需签字人+日期，不填意见）：

1. **部门审核**（申请人所在科室部门负责人）
2. **生产管理科**（生产科负责人；纸质单要求其在各子项密级处手签密级和姓名）
3. **科研开发室**
4. **分管领导**（打印栏为「开发室分管领导」）
5. **资料交接**：移交人（申请人侧）+ **资料员**（资料室接收确认）

缺任一必填签字人不能点审批通过。通过后由资料室确认实物交接并上传签批交接单、资料照片。部门申请账号只能提交、撤回，不能打开审批页点通过。

### 资料借出（审批出库）

菜单：`资料流转` → `审批出库`。仅资料室办理账号。四级审核审批均须完整才能通过：

1. **申请部门审核**（借出部门负责人）
2. **资料室负责人**
3. **生产科负责人**
4. **生产副院长**

通过后资料室办理实物交接、上传签批交接单与资料照片，再「业务办结」。部门账号只办「借出申请」。

### 资料归还（审批入库）

菜单：`资料流转` → `审批入库`。仅资料室办理账号。按是否灭失分流：

- **完好归还**：签批交接单只需 **部门负责人**；系统审批区只录这一人，不展示其他审批人。
- **存在灭失**：须借出时全部四级签字人均手签并录入：部门负责人、资料室负责人、生产科负责人、生产副院长。灭失说明必填。

通过后再确认实物交接（归还人、资料管理员、交接日期）并上传签批单后办结。指定归还目标盒也仅资料室可做。

### 入网（入网审批）

菜单：`年度资料出入网管理` → `入网审批`。仅资料室办理账号。通过前须先按线下结果核实各明细密级，可补录服务器路径、资料路径和借出硬盘归位档口。

签字人（办结前须齐）：**部门负责人**、**生产管理科负责人**、**资料室负责人**、**分管领导**，以及交接栏 **移交人**、**资料员**。打印单对应「申请部门 / 生产管理科 / 资料室 / 分管领导 / 入网交接」。部门账号只办「入网申请」。

### 出网（出网审批）

菜单：`出网审批`。仅资料室办理账号。通过后、确认交接前，须从离线介质补录电子目录与数据量。

签字人与入网相同：部门负责人、生产管理科负责人、资料室负责人、分管领导，以及移交人、资料员。打印单「分管领导」栏名可能随目的地显示为分管生产或分管资料副院长。部门账号只办「出网申请」。

### 在网数据处置

菜单：`在网数据处置`。仅资料室办理账号（含新增、提交、审批、办结）。无部门「提交申请」侧。

审核 / 审批栏：**资料室负责人**（审核）、**分管资料副院长**（审批），仅签字与日期。点「审批通过」会自动填这两人姓名与日期，姓名可改。办结前须上传签批单。

### 年度资料离库处置（模拟 / 电子）

菜单：`离库处置`。提交、审批、办结均资料室办理账号。

纸质签批：

- **审核**：资料室负责人、生产科负责人（签字+日期）
- **审批**：分管资料室副院长、分管生产副院长（签字+日期）

流程：提交 → 打印签批单线下签 → 审批通过 → 确认可上传 → 上传签批单（销毁另须处置资料照片）→ 办结。含低格留盘、撤柜时还须勾选确认。

### 历史存档离库处置

菜单：`历史存档资料管理` → `资料离库处置`。仅资料室办理账号。

审核 / 审批：**资料室负责人**、**分管资料副院长**（姓名可改，日期自动填）。三种处置方式办结前都须确认实物已撤柜；销毁另须处置照片。

### 硬盘出库（出库审批）

菜单：`介质管理` → `硬盘` → `出库审批`。仅资料室办理账号。

系统录入 **审核人**（默认申请人所在部门负责人）、**审批人**（默认资料室负责人）。打印栏为「申请部门审核」「资料室负责人签批」。通过后确认实物交接、上传签批交接单、办结。部门账号只办「出库申请」。

### 硬盘归还（审批入库）

菜单：`硬盘` → `审批入库`。仅资料室办理账号。

- **正常归还**：审核人（部门负责人）+ 审批通过 + 指定空白硬盘归位档口 + 交接办结。
- **损坏归还 / 挂失登记**：须填特殊情况说明并打印签批交接单；纸质还须归还人、申请人所属部门负责人、资料室负责人与资料室经办人签字。损坏须归损坏专用档口；挂失无需归位。

### 硬盘离库处置

菜单：`硬盘` → `离库处置`。仅资料室办理账号。未挂在用资料袋的盘才能选。

系统「审批通过」记下当前办理人。打印「资料室审批」外，另有资料室负责人、资料室分管领导签字栏（线下签；办结后重打按办结日预填）。须上传签批单与硬盘照片后办结。已挂资料袋的硬盘改走「电子资料离库处置」，审批节点按年度资料离库。

### 不走审核审批的业务

下列由对应权限账号直接办理，**没有**「审批通过」：

- 资料立档、存量硬盘/文本直办立档
- 模拟/电子迁档、开柜迁档
- 模拟/电子资料盘库、硬盘盘库登记（确认登记即办结）
- 项目信息维护、历史台账导入编辑、档案柜登记改用途
- 个人改密、系统设置中的运维项（服务器路径见「网管负责人」）

网管负责人维护服务器路径也不走资料审批。

光盘无独立审批菜单，随资料出库/归还/盘库/离库走对应资料单。

## 待办、打印与签批

### 单据状态与办理节奏

多数单据共用这套状态（列表筛选里能看到）：

| 状态 | 含义 |
| --- | --- |
| `当前草稿-待提交` | 申请人编辑中 |
| `已提交-待审批` | 等资料室审批 |
| `已审批-待实物交接` | 等交接 |
| `已实物交接-待上传签批交接单` | 等扫描件 |
| `已上传签批交接单-待办结` | 签批已传、待办结 |
| `已办结（业务已闭环）` | 终态 |
| `已作废（撤回）` / `已作废（强制）` | 作废 |

办理节奏：`保存草稿 → 提交 → 审批通过 → 确认实物交接 → 上传签批扫描件 → 确认办结`。盘库类单据没有审批，确认登记即办结。

### 待办与个人设置

1. 右上角 `待办` 列出当前账号待处理事项（数量超过 99 显示 99+）；每条含单号与所处环节。
2. 待办弹窗：`知道了` 标记当前待办为已读，`关闭` 收起。
3. `个人设置` 可调：`登录后显示待办弹窗`、`主界面显示待办角标`、`点击"知道了"后将当前待办标记为已读`、`待办刷新频率(秒)`（5~3600，默认 15）、`待办展示条数`（1~200，默认 20）。`保存设置` 生效，`恢复默认` 还原。
4. 未办结或未传必备附件时，角标会一直提示。

### 打印与附件

> 办结前打印：交接双方签字栏和日期栏留白。已办结后再打：才预填姓名和办结日期。

- 交接双方 = 当事人（申请人/领用人/归还人等）+ 资料室资料管理员。
- 部门审核、资料室负责人等非交接栏：审批完成后即可预填。
- 附件区常见分类：`签批交接单`、`资料照片`、`证明材料`、`其他附件（可选）`；离库类为 `签批单`、`处置资料照片` / `硬盘照片`。每区支持 **上传** / **高影仪直拍**，行内 **查看** / **删除**。格式限 PDF 与常见图像。
- 高影仪直拍：选拍摄设备，可勾自动切边、形变校正、去黑边、白底文档、去阴影、自动扶正、镜像、锐化（按用户保存在本机），拍摄后 `确认上传`。
- 申请时若「附有证明材料」选「是」，办结前必须上传证明材料扫描件。
- 查看弹窗（只读）办结后仅可增补「其他附件」，不能删除已有附件。

### 常见打印单据名

| 业务 | 单据名 |

### 卡在办结时先查

- 还没点过「确认实物交接」或「确认可上传」。
- 签批单未传；销毁类未传现场/资料照片。
- 声明有证明材料但附件区是空的。
- 出网单：电子介质数据量与目录/文件明细还没补录。

记问题时写下：菜单路径、单号、当前角色、列表状态、期望与实际。

## 年度项目管理

菜单：`年度项目管理` → `项目信息设置`。

字段：项目名称、项目编码、实施年度、资金管理部门、备注。建档申请、存量直办、立档台账、出入网都会引用项目。

- 按钮：`新增项目`、`编辑项目`、`删除选中`、`年度项目检索`（筛选 `年度`、`关键词`）。
- **权限**：增删改仅资料室办理账号；其他人仅浏览与检索（提示「仅资料室资料管理员可编辑项目信息。」）。系统管理员也不能替代。
- 建议先有项目再建档。存量直办页可用 `查看年度已有项目`；年度、项目为开放下拉，也可手输新值，选中已有项目会带回项目编号。

## 资料建档与立档

菜单：`年度资料档案化管理` → `资料建档`。

正规路径：**建档申请（部门）→ 申请审批（资料室）→ 资料立档（资料室）**。模拟资料先入档案盒再入档口；电子资料先入介质袋（硬盘/光盘）再入磁盘柜。

### 建档申请（部门侧）

菜单：`建档申请`。列表标题「资料登记申请办理表」：`新增申请`、`打开申请`、`撤回申请`、状态/申请年度筛选、`刷新列表`。列表列含归档盒/编号与归档位置。

编辑窗标题「资料立档 · 待编单 · 状态」，顶部有流程提示。分区与必填项：

**1. 资料信息**：`资料名称 *`；`所属项目 *`（年度 + 项目两级下拉）；`资料来源 *`（内部 / 外来 / 存量直办）；`提供单位 *`（内部=部门下拉，外来=手填）。

**资料介质（电子）/（模拟）**（至少维护一组）：`+ 添加资料介质（电子）` 或 `+ 添加资料介质（模拟）`，组内再 `+ 添加资料子项`。

- 介质工具栏：`介质`（电子/模拟）、`类型`（电子：U盘/光盘/硬盘/内网；模拟：打印纸/绘图纸/打印相纸/感光胶片/感光相纸）、`数量`、`处置`（介质带回/介质留存/无需处置）。
- 子项字段：`子项名称`、`密级`、`份数`（电子通常为 1）、`资料类型`、`所属子类`、`组织形式`、`备注`。
- 电子子项可点 `填写合规目录` 自动生成 `\年度\项目\资料名称\子项名称` 存储目录；格式说明与示例见输入框提示。
- 电子介质行内 `借出硬盘：` 是/否；为是时 `介质编号` 下拉（当前登记人名下借出未还的盘）；`使用库内空盘：` 是/否，为是时点 `选择` 挑库内空盘；再填 `硬盘是否归还：` 与 `预计归还日期`。

**2. 申请信息**：`归档目的 *`（选「其他」须填 `说明`）；`附有证明材料：` 是/否（是须填 `名称`，扫描件由资料室在审批环节上传）；`其他要求`；`申请人 *`、`部门 *`、`日期 *`。

**操作：** `保存草稿` → `提交申请`（确认弹窗提示「提交后所有审批信息将被重置」）→ `打印申请`。未提交或可撤阶段用列表 `撤回申请`；提交后部门侧不能再改内容。

### 申请审批与交接（资料室侧）

菜单：`申请审批`。列表「资料登记审批办理表」：`申请->查看`、`申请->审批`、`强制作废`、状态/申请人/申请年度筛选、`刷新列表`。

**审批节点（各节点仅需签字人 + 日期，无需意见）：** `部门审核` → `生产管理科` → `科研开发室` → `分管领导` → `资料交接`（移交人 + 资料员）。

**办理顺序：**

1. 打开「已提交-待审批」单。顶部横幅提示先 **根据线下审批结果核实并登记各子项密级**（弹「核实资料密级」确认）。
2. 补齐各节点签字人与日期（缺任一必填签字人不能通过）→ `审批通过` → 状态「已审批-待实物交接」。
3. 申请人携资料与打印单到资料室 → `确认实物交接`。
4. 附件区分别上传 `签批交接单`、`资料照片`（均必传）；声明有证明材料再传 `证明材料`；`其他附件（可选）`。每区支持 `上传` / `高影仪直拍`，行内 `查看` / `删除`。格式限 PDF 与常见图像。
5. `确认办结` → `打印交接单`（此时才预填姓名与办结日期，可出存档副本）。

> 办结只表示申请闭环，资料还没落到柜里——接着到 `资料立档`。出网办结生成的建档草稿会带提示「本单由出网单 XXX 转入」，在列表里继续补全，不要当全新申请重填。

### 资料立档 · 模拟介质（资料室）

菜单：`资料立档` → 页签 `模拟介质立档（待办/已办）`。

1. 左侧 `模拟介质待立档池`：按 `年度筛选` + `刷新`；Ctrl/Shift 可多选同一项目的记录。
2. 第一步 `资料登记信息`：项目名称、归属年度（只读）。
3. `资料子项列表`：勾选 **本次拟入盒** 的子项（绿底=已入盒，黄底=未入盒），可分多次立完。
4. `选择立档方式`：`新建档案盒` 或 `并入选中档案盒`（该项目当年已有盒时列出可选）。
5. 第二步 `选择物理存放位置`：`档口编号` 下拉 + `建议档口位置` + `档口占用快照`；并档时无需再选位置。建议失败会提示手动选择。
6. 第三步 `赋码与确认`：`档案盒编号` 可 `自动生成`；核对 `档案盒规格`、`格内现有盒数`、`备注`。
7. `执行模拟介质立档` → 成功提示盒号与入盒子项数。标准滑道柜只能落入 `年度资料专用档口` 或 `混用档口`。

### 资料立档 · 电子介质（资料室）

菜单：`资料立档` → 页签 `电子介质立档（待办/已办）`。八步向导：

1. 第一步 选 `电子介质表单`（单选）：`当前`、`电子介质表单`、`处置方式`、`介质编号`、`立档状态`（未启动立档 / 已部分立档 / 已全部立档）。**每次只办一个介质条目，「已全部立档」的不再重复立。**
2. 第二步 `资料明细`：自动列出该介质下全部明细，未入袋的一并参与，**不能拆开只立一部分**（已入袋绿底 / 未入袋黄底）。
3. 第三步 选立档方式（四选一）：`选择一块空硬盘，立档`（点 `选择库内空盘` 挑空盘作载体、转数据盘入袋）／`使用该硬盘直接立档`（借出/外来留存盘直接作数据盘）／`使用1张光盘，立档`（每张光盘单独立档、不允许并档）／`数据并入本项目已立档硬盘`（沿用原电子袋与原数据硬盘）。
4. 第四步 `资料立档明细`：核对 `介质总容量`、`可用容量`；**`立档存储路径` 列可编辑**（浅黄底橙框），拷贝型已按 `\年度\项目\资料名称\子项名称_001\` 预填，确认弹「是否已对立档存储路径进行了确认？」。
5. 第五步 `外来硬盘基本信息登记`：外来留存盘点 `登记外来硬盘`（登记成功自动带入编号，执行立档时同步入库）；与借出记录一致或并档场景会提示跳过本步。
6. 第六步 `外来硬盘格式化后物理存放位置`：点 `空白硬盘入库推荐档口` + `档口占用快照` 为格式化后的空盘定位；不适用时提示跳过。
7. 第七步 `资料介质物理存放位置`：`档口编号` + `建议档口位置` + `档口占用快照`；推荐年度数据硬盘/光盘专用档口空位（含档内序号）。
8. 第八步 `赋码与确认`：`介质袋编号` `自动生成`；核对 `袋内载体`、`袋内硬盘数量`（光盘袋为袋内光盘数量）、`资料摘要`、`备注`。
9. `执行电子介质立档` → 弹「拟执行逻辑预览」确认后写入。

> 硬盘袋一次只能关联一块硬盘；并入时不能换盘。空盘推荐失败提示先在磁盘柜开柜界面设置空白硬盘专用档口。

### 存量硬盘资料直办立档

菜单：`存量硬盘资料直办立档`。资料室直接登记 + 电子立档，**无需申请审批**。根目录必须符合 `年度/项目/资料名称/子项/…`，一块盘只允许一个年度/项目。

1. **1. 硬盘参数**：`硬盘编号` `生成编号`；`序列号` 旁 `读取本机` 可从本机物理盘回填序列号、品牌、容量、类型、接口、出厂日期（系统盘与虚拟磁盘不可选用）。
2. **2. 目录扫描**：`根目录` `选择目录` → `扫描`；`年度`、`项目` 为开放下拉（也可手输新值）；`查看年度已有项目` 辅助选值。
3. **3. 立档默认值与档口**：来源固定 `存量直办`、提供单位固定 `资料室`、库管模式默认 `院管资料、长期存档`、密级默认 `秘密`；`数据档口` 用 `推荐空位`、`档口快照`。
4. **4. 扫描预览**：核对资料名称、子项、组织形式、数据量、文件数、立档路径（共 N 份资料、M 个子项）。
5. `确认立档`：弹确认框（含年度/项目、档口、预览摘要）；**确认前编号仅为预览、不占号**；同年度/项目已有袋时仍新建第二袋。序列号已入库时会提示状态并按空盘转数据盘处理。

### 存档文本资料直办立档

菜单：`存档文本资料直办立档`。以档案盒为单位手工登记纸基模拟资料，直接建档 + 模拟立档，无需审批。载体限打印纸、绘图纸、打印相纸、感光胶片、感光相纸。

1. **1. 年度 / 项目**：实施年度、项目名称（开放下拉）、项目编号、`查看年度已有项目`。
2. **2. 立档默认值**：资料名称；来源固定 `存量直办`、提供单位固定 `资料室`、库管模式默认 `院管资料、长期存档`。
3. **3. 资料介质（模拟）***：`+ 添加资料介质` → 每组选载体类型（一单只能一种载体）→ `+ 添加资料子项` 填子项名称、密级、资料类型、所属子类、组织形式（散页/装订）、份数（按子项数自动计算）。
4. **4. 档案盒与落位**：预览 `档案盒编号`（确认前不占号）；`盒规格`（标准 10/5/3/2cm、非标 10cm）；`资料档口` `刷新档口` + `推荐空位` + `档口快照`；填 `盒备注`。
5. `确认立档`：一次只确认 **1 个新盒**；批量走 `从 Excel 导入`。

**Excel 导入**（`从 Excel 导入` 按钮）：

- 先选工作表；可勾选 `以文本行为单位展开资料子项`（「子项名称」单元格内每一非空文本行拆为一条子项）。
- 必要列表头：`年度`、`项目名称`、`资料名称`、`子项名称`、`份数`、`档案盒编号`、`档案盒规格`（年度须四位）。按表内物理盒号导入，不改推荐档口。
- 预览表列：序号、年度、项目名称、资料名称、规格、物理位置、子项、状态（可导入 / 不可导入）、校验。
- `导入可立档盒`：跳过审批按表内位置导入；失败盒不阻断后续盒；完成提示成功/失败/跳过数。

### 立档台账

菜单：`立档台账`。按立档编号核对盒/袋号、柜位、生命周期。

- 筛选：`档案年度`、`项目`、`介质`（全部/模拟/电子）、`状态`（在库/借出中/已转移/已销毁/已处置）、`副本`（全部/原件/备份）、`立档自/至`、`关键词`（模糊匹配编号、名称、位置等）、`目录/文件`（通配符，仅电子）。
- `查询` / `重置` / `导出`（Excel）/ `刷新`；同建档表单号默认折叠，可展开。
- 点行后在下方看详情：建档与资料信息、存放与容器（立档时快照 + 当前值）、立档与生命周期、`流转履历`、`关联出库单 / 流程节点`、`电子介质目录 / 文件明细`。

## 资料检索

菜单：`年度资料档案化管理` → `资料检索`。

> 推荐路径：检索勾选 → 加入筛选池 → （可选）保存为结果集 → 在检索池点「发起借出申请 / 发起入网申请」。不要在系统外零散记编号再手工录入。

### 三种检索页

**资料检索(综合模式)**

1. 条件：`年份`、`关键词`（可匹配资料名称、单号、申请人、项目名称、提供单位）、`状态`、`项目`。
2. `🔍 查询` / `重置`。
3. 结果列：档案编号(表单号)、资料名称、所属项目、提供单位、申请人、申请日期、登记状态、档案盒/介质袋编号、物理位置、立档状态；行内 `查看` 打开资料详情页。

**电子介质资料检索 / 模拟介质资料检索**（同一页面按介质切换）

1. 条件：`年份`、`项目`、`关键词`（表单号、资料名称、子项名称、提供单位等）、`条目类型`（仅电子：全部 / 目录 / 文件）、`目录/文件名称`（支持 `*` 任意字符、`?` 单字符；`\` 转义）、`状态`（生命周期：全部 / 在库 / 借出中 / 已转移 / 已销毁 / 已处置）。
2. 模拟页结果按 **档案盒分组**，可展开盒批量勾选子项，子项下可再展开备份副本（提示「另有 N 份备份」）。
3. 电子页结果默认折叠备份副本，按需展开。
4. 内容区按钮：`全部选择`、`清空选择`、`切换选择`、`选中加入筛选池`、`本页全部加入`、`检索池`。

### 筛选池与结果集

- 池内操作：`移出选中`、`清空筛选池`；`份数` 列可编辑（拟申请份数）。
- `保存筛选池为结果集`：须填 `结果集名称`，`备注` 可选；系统会校验份数，含「借出中」提示时仍允许保存（弹确认）。
- 结果集可在借出申请、入网申请时用「通过检索集登记」引用，避免重复检索。

### 检索池

菜单：`检索池`。左侧池列表（编号、名称、条数、状态、创建人、更新时间），右侧池明细。

1. 切换 `电子介质` / `模拟介质`；筛选 `年度`、`介质类型`、`关键词`、`状态`（草稿 / 已确认 / 已引用）；勾选 `仅看我创建的`。
2. 池属性可编辑 `名称`、`状态`、`备注`，`保存修改` 生效。
3. `查看资料` 打开详情；`移出选中条目` 删行（池至少保留一条）。
4. `发起借出申请`：有选中行只带选中行，否则带整池（ToolTip 有说明）。
5. `发起入网申请`：规则同上；电子池可生成存档资料入网草稿。

> 权限：一般人只能浏览、编辑本人创建的池；资料室办理账号可看全部。已借出、盘库异常、已离库条目带提示，不能当正常在库资料领用；申请份数不得超过立档份数。

### 资料详情页

从各处 `查看` 打开，分区：一、申请基本信息；二、资料介质与内容（电子/模拟介质、证明材料，子项默认折叠，可 `全部展开` / `全部折叠`，含目录/文件明细）；三、审批与交接信息；四、附件材料；五、立档结果（模拟档案盒、电子介质袋）。从检索进入时可在第五区勾选子项或目录/文件 `加入筛选池`。

## 资料借还

菜单：`年度资料档案化管理` → `资料流转`。含 `借出申请`、`审批出库`、`归还申请`、`审批入库`、`流转台账`、`跨域流转台账`。

### 借出申请（部门）

列表「资料借出申请」：`新增申请`、`打开申请`、`撤回申请`、状态/申请年度筛选、`刷新列表`。

1. `申请原由` 必填；`资料去向`：`本部门（内部）` 或 `外部（单位）`——后者必填 `外部单位`；`附有证明材料` 选是须填名称；可填 `资料摘要`。
2. `通过检索集登记拟领用的资料` 引入盒/袋明细（先建好检索集再点，弹窗内 `检索` → 选结果集 → `确定`）。
3. 每个 **盒/袋卡片内** 有「领用设置（本盒/袋统一）」：`领用方式`（模拟 `提档`/`复制`；电子 `提档`/`拷贝`，**长期存档电子介质仅支持拷贝**、原件留库）；`提档资料是否归还`（模拟）或 `硬盘是否归还`（电子）与 `预计归还日期`；拷贝时选 `拷贝目标介质`（`自备U盘`/`自备硬盘`/`光盘`/`库内空盘`，选库内空盘须点 `选择` 挑盘）；`是否使用库内空盘` 及共享空盘提示按选择联动。
4. 明细行 `份数`（拟领用份数）可编辑；`详情` / `删除` 管理行。
5. `保存草稿` → `提交申请`（弹「确认按以上逻辑提交申请？」）；可 `打印`；未提交前 `撤回`。

> 提档校验拟提份数 ≤ 可借份数；办结后扣库存，需归还的产生待还。复制/拷贝不扣库内份数。征用库内空盘会写征用锁，锁定期禁止并行占用。

### 审批出库（资料室）

列表「资料借出审批出库」：`申请->查看`、`打开办理`、`强制作废`（仅未审批单）、申请人多选筛选、`刷新列表`。

打开办理后按横幅顺序：**审批通过 → 确认实物交接 → 分区上传附件 → 业务办结**。

1. 打开「已提交-待审批」单，系统自动回填默认审批签字人（按申请部门与角色），可手工修改；审批区四节点：`部门审核`、`资料室负责人`、`生产科负责人`、`生产副院长`，各只需签字人 + 日期。
2. `审批通过`（四级签字人+日期不全会被拦截：「四级审批信息尚未完整，请补全后再审批通过。」）→ 状态「已审批-待实物交接」。
3. `确认实物交接`（办理交接人等）。
4. `打印交接单`（办结前签字留白）+ `业务助手` 逐项核对（见下）。
5. 附件区上传 `签批交接单`、`资料照片`（必传）及声明的 `证明材料`；`其他附件（可选）`。
6. `业务办结` → 台账同步：提档资料变借出/部分可借；电子提档同步硬盘/光盘台账；不需归还的提档可能触发空盒自动释档。

**业务助手**（资料出库业务助手清单）：按「办理前核对 / 档案盒与介质袋 / 电子介质与硬盘 / 本单资料明细 / 涉密与特殊事项 / 交接与系统归档」分组列检查项，逐项勾选确认，可 `打印清单` 留存。

### 归还申请 / 审批入库

菜单：`归还申请`（借出人/经办填单）、`审批入库`（资料室）。左侧 `待归还出库单`（可筛 `超期未还`）与 `归还登记单` 两栏。

**发起归还（部门侧）：**

1. 在待还出库单 `查看借出详情`（可 `打印详单`）→ `发起归还`。
2. 明细逐行填 `完好归还份数`（上限=借出份数）与 `灭失份数`（只读=借出-完好）；有灭失须填 `灭失说明`（写入签批交接单）。
3. 原盒失效的行（容器状态列提示）点 `指定目标盒`，弹窗选一个在用档案盒作为入库目标；新开空盒只能落入年度专用或混用档口。
4. 借出后盒位有变更时系统弹「盒位已变确认」，确认后办结归入当前盒位。
5. `保存草稿`、`提交申请`、`打印签批交接单`（线下签字后提交）、`撤回作废`。

**审批入库（资料室）：**

1. 打开归还单，按是否灭失分流签字：**完好归还** 只需 `部门负责人`（签字+日期+意见）；**存在灭失** 须借出时全部四级 `部门负责人`、`资料室负责人`、`生产科负责人`、`生产副院长`。
2. `审批通过` → `确认实物交接`（归还人、资料管理员、交接日期）→ 上传 `签批交接单` 扫描件 → `确认办结`（冲销台账并归位；提示「办结后将冲销出库提档对资料台账的影响，且不可撤销」，灭失致空盒时提示线下物理处置空盒）。
3. 另有 `打印交接单`、`强制作废`。

> 灭失计入出库灭失，与盘库丢失是两回事，不要混填。归还可指定归还目标盒，仅资料室可操作。

### 流转台账 / 跨域流转台账

- `流转台账`：按「容器 → 业务单 → 明细」三级时间线浏览出库/归还落账与申请节点。条件：时间自/至、业务（资料出库/资料归还）、单号、节点（流程预订/流程撤销/办结同步）、申请人、操作人、关键字；可切「有流转记录 / 无流转记录 / 全部容器」。仅查询，不能改状态。
- `跨域流转台账`：浏览立档电子资料复制入网等跨域流水（如「立档资料复制入网」）。支持入网单号检索、`近30天` / `近90天` / `全部时间` 快捷、`导出` Excel。

## 资料迁档

仅资料室。迁档 **无审批**，`生成预览` → `确认迁档`（提示「此操作无需审批，提交后立即生效」）即时生效。完成后到 `迁档台账` 核对迁前迁后位置。

档口用途须匹配：年度模拟盒 → `年度资料专用档口` 或 `混用档口`；电子袋/数据盘 → 对应 `年度数据硬盘专用档口`、`年度数据光盘专用档口` 等；空白盘 → `空白硬盘专用档口`。

### 模拟介质资料迁档

菜单：`模拟介质资料迁档`。迁档模式二选一：

- `物理位置迁移`：整盒换档口。选源档案盒与关联资料 → 目标档口（A/B 面）+ `档口占用快照` → 可勾选「迁入空盒（目标档口新建盒，源盒销号）」并选新盒规格。
- `并入已有档案盒`：选目标已有盒，盒内资料并入，源盒销号。

### 电子介质资料迁档

菜单：`电子介质资料迁档`。迁档模式：

- `物理位置迁移`：电子袋整袋换档口。
- `迁入空盘/空袋`：指定目标档口 + `空盘选择`，数据写入新载体。
- `并入同项目硬盘`：并入目标电子袋。

可勾选 `保留原件，执行备份机制`（原件不动，目标介质生成备份副本）。并档后按提示确认 **原盘已格式化按空盘管理** 或 **原光盘已销毁**。

### 开柜现场迁档

菜单：`档案柜管理` → `档案柜登记`，打开柜体。标准模式下支持拖拽：**紫色高亮=可放，红色高亮=不可放**。

**点选迁档：**

- 单击选中；Ctrl 同档口多选同类型；Shift 范围选（档案盒多选仅限同档口）。
- 工具栏或右键 `设为迁档对象` → 到目标档口点 `迁档到此档口`（或直接拖放）→ 确认「确认执行迁档？」。
- 电子袋标 `X`（损坏载体）仍可整袋迁移；标 `失`、`销` 的不能当迁档源。损坏硬盘/光盘在专用档口内换位也用开柜操作。

**整档口批量搬迁：**

- 源档口右键 `设为批量搬迁源` → 打开同柜/跨柜/跨面目标 → 右键 `搬迁到此档口` → 预览后执行。
- 目标档口一般须全空（空白/损坏专用档口按剩余盘位计）。年度与历史盒混放的档口不能当搬迁源；历史盒自身的「混放待梳理」标记不影响迁档（与普通历史盒同规则）。迁出后余下实体保持原序号。

> 本会话有成功迁档时，关窗前系统会强制先 `打印「本次开柜迁档汇总清单」`（资料室开柜迁档操作汇总清单）并确认线下核对后才能关闭。

## 盘库与离库

仅资料室。先盘库记中间态，再离库清账。盘库 **无审批**：`保存草稿` → `确认登记办结`（确认语「办结后即时写入台账，不可再改」），确认即生效。

> 盘库导致的空盒/空袋仍占档口，开柜标 `失` / `销`，不标空。出库不还、归还灭失等业务空盒才会按规则自动释档。

### 模拟资料盘库 / 电子资料盘库

菜单：`盘库登记` → `模拟资料盘库` / `电子资料盘库`。列表：`新增登记`、`打开办理`、`撤回作废`，按状态、年度、关键词 `查询` / `刷新`。

**登记类型：**

| 轨 | 登记类型 | 说明 |
| --- | --- | --- |
| 模拟 | `盘失登记` | 须填丢失份数，且不超过该子项可用份数 |
| 模拟 | `拟销登记` | 无存档价值；丢失份数列只读 |
| 电子 | `盘失登记` | 对象是袋内硬盘/光盘，不是袋子本身 |
| 电子 | `损坏登记` | 改介质台账为在库(损坏)；换档口请走开柜迁到损坏专用档口，不要在盘库里挪口 |
| 电子 | `拟销登记` | 出库待还大于 0 时不能拟销；拟销须整批等于当时库内份数 |

操作：左侧候选（可按档口筛选）用 `加入 →` / `← 移除` 挑选子项或介质 → 填 `登记说明`（可空，默认用登记类型）、`备注` → `保存草稿` / `确认登记办结` / `撤回作废`。

> 同一介质不能同时挂未办结的：资料盘库、硬盘盘库、硬盘离库、资料离库。

### 模拟 / 电子资料离库处置

菜单：`离库处置` → `模拟资料离库处置` / `电子资料离库处置`。只清盘库产生的 `盘失` / `拟销` / `损坏` 中间态。单号前缀 `资离-处`。

列表：`新增处置`、`打开办理`、`撤回作废`；筛选含「进行中（待办结前）」。

**弹窗七态按钮顺序：** `保存草稿` → `提交` → `打印签批单` → `审批通过` → `确认可上传` → 上传附件 → `办结`（旁路 `撤回作废`、`关闭`）。须先「确认可上传」再传附件。

**明细选取与赋值：** 左侧候选按盘库中间态列出，勾选后 `移入 ▶` / `◀ 移出`；先勾选同一离库原因的明细，再选处置方式点 `赋值` 批量写入。

**原因 → 允许处置方式（系统强制）：**

| 情况 | 允许处置方式 |
| --- | --- |
| 模拟盘失 | 库内注销 |
| 模拟拟销 | 离库销毁 |
| 电子盘失 | 库内注销 |
| 电子损坏 | 离库销毁 |
| 电子光盘拟销 | 离库销毁 |
| 电子硬盘拟销 | 低格留盘（默认）或 离库销毁 |

**低格留盘：** 明细行 `空盘档口` 列在 **办结前** 填写目标空白硬盘档口（`推荐` / `快照` 辅助，不做预占用）；办结须勾选 `已确认硬盘低级格式化`。办结后台账转 `在库(空盘)`、位置写入空白档口。

**撤柜确认：** 本单将释档空盒/空袋时须勾选 `已确认空盒/空袋物理移除`。

**附件：** `签批单` 必传；含 `离库销毁` 还须 `处置资料照片`。列表可看已传签批单、已传照片列。

**签批单：** 审核=资料室负责人、生产科负责人；审批=分管资料室副院长、分管生产副院长（均签字+日期）。办结前签字留白，办结后重打按角色预填默认人名（日期取办结日）。

> 已挂在用资料袋的硬盘不要走「介质管理 → 硬盘 → 离库处置」，应走本页电子离库处置。

## 档案柜

菜单：`档案柜管理`。

- `档案柜登记`：`新增柜子`、`编辑选中`、`删除选中`、`刷新`。仅资料室（提示「仅资料室资料管理员可办理档案柜登记。」）。
- `档案柜检索`：`打开柜体 A 面` / `B 面`、`刷新`。所有人可开柜查看，不能改柜。

### 柜体种类与编号

| 种类 | 布局 |
| --- | --- |
| 标准滑道式档案柜 | A/B 面，6 层 3 格 |
| 立式文件柜 | A 面，4 层 1 格 |
| 卧式文件柜 | A 面，1 层 1 格 |
| 防磁磁盘柜 | 单/双门，抽屉分层，单面打开 |

柜体编号规范：`甲~癸`（10 个）+ `子~亥`（12 个），共 22 个。编辑柜体时可改宽/高/深；**先规划面数、层数、列数再保存，有占用时不要随意缩小柜体**；柜名会写入盒位和硬盘位置，改名要谨慎。

### 开柜界面

工具栏：`全选`、`反选`、`设置用途`、`清空选择`、（迁档模式下）`设为迁档对象`；显示 `标准` / `简洁` 切换。单击选中，Ctrl/Shift 多选，双击或右键看详情；多选后可统一 `设置用途`（仅空档口可改用途）。

**标准滑道柜档口用途：** `未定义` / `年度资料专用档口` / `历史资料专用档口` / `混用档口`。立档、归还新开盒、年度迁档会按用途拦截。

**防磁磁盘柜档口用途（开柜里设置，启动不会冲掉已保存项）：** `空白硬盘专用档口`、`年度数据硬盘专用档口`、`年度数据光盘专用档口`、`历史数据硬盘专用档口`、`历史数据光盘专用档口`、`损坏硬盘专用档口`、`损坏光盘专用档口` 等。未配置过的格口启动时默认补 `空白硬盘专用档口`。

**档案盒放置方向：** `盒脊向外` / `盒面向外`（盒位编辑时选择）。双击盒/袋看内容。

**角标与标记：**

| 标记 | 含义 |
| --- | --- |
| 右上 `失` / `销` | 盘库异常（不标空） |
| 右下 `待还` | 有出库待还 |
| 左下 `预订` | 已被出库申请预订 |
| 左上 `混` 等 | 混放等特殊状态 |
| `X` | 电子袋内载体损坏 |

空白盘位置只精确到档口；数据盘带档内序号。

> 同一档口 = 柜号 + 柜面 + 层号 + 列号。盒序号、硬盘档内序号只是格内占位。

## 出入网

菜单：`年度资料出入网管理`。部门申请、资料室审批；在网数据处置仅资料室。单号前缀：入网 `网-入-申`、出网 `网-出-申`、在网处置 `网-处-申`。

### 入网申请（部门）

菜单：`入网申请`。列表：`新增入网`、`打开办理`、`撤回作废`；筛选状态、年度、关键词。列表列含 `数据源`、`关联业务进度`。

编辑窗「入网申请 · 待编单 · 状态」：

1. **数据来源 \***（三选一，决定明细来源）：`存档资料`（明细唯一来自电子资料检索结果集，从检索池 `发起入网申请` 最顺，提供部门固定为资料室）／`档外资料（院内）`（提供部门下拉院内部门，`+ 添加资料介质（电子）` 手工录入明细）／`档外资料（院外）`（提供部门手填，同样手工录入）。
2. **1. 资料信息**：`资料名称 *`、`提供部门(单位) *`、`服务器路径`（下拉，网管负责人维护）、`资料路径` + `填入默认资料路径`。默认组成为 `入网\年度\项目\资料名称`（共用服务器路径时前加申请部门）；各子项名称作为该路径下的子目录。
3. **入网明细 \***：子项含密级等；电子介质行内同建档的 `借出硬盘` / `使用库内空盘` 逻辑。
4. **2. 申请信息**：`申请说明 *`、`其他要求`、`备注`；`附有证明材料：` 是/否（是须填名称）。
5. 按钮：`保存草稿`、`提交申请`、`打印申请`（打印单：年度资料入网申请审批单）。

### 入网审批（资料室）

菜单：`入网审批`。`打开办理` 后按横幅顺序：

1. **核实明细密级**：只读区顶部提示可在「审批通过」前编辑各明细密级。
2. **补录路径**（黄底补录区）：审批通过前可补录整单共用的 `服务器路径`、`资料路径`（`填入默认资料路径` 辅助）。
3. **回填签字**：点 `回填默认审批信息` 按当前用户与业务规则回填。签字节点：`部门审核`、`生产管理科`、`资料室`、`分管领导`，以及资料交接 `移交人`、`资料员`（各签字+日期，无需意见）。打印单对应「申请部门 / 生产管理科 / 资料室 / 分管领导 / 入网交接」。
4. `审批通过` → `确认实物交接`。
5. **借出硬盘归位**（申请勾选了随入网归还借出硬盘时）：为每块盘指定 `空白硬盘归位档口`（`推荐档口` / `档口快照`）。
6. 附件：`签批交接单` 必传；`资料照片` 标「入网无需」；声明的 `证明材料` 必传；`其他附件（可选）`。
7. `确认办结` → 写入 **在网台账** → `打印交接单`。

> 在网数据生命周期：`在网` → `出网中` → `曾出网` / `处置中` → `已处置`。

### 出网申请（部门）

菜单：`出网申请`。`新增出网` 后先选 **目的地 \***：

| 目的地 | 填写要点 |
| --- | --- |
| `出网（院内）` | 生产网选 `服务器路径`；`出网资料所在具体路径` 按规范自动生成（先选路径并完善年度/项目/资料名称） |
| `出网（院外）` | 同上；离线介质允许光盘/硬盘/U 盘等 |
| `资料室存档` | 须选 `库管模式 *`；办结后生成 **待立档任务**（目标建档表单编号），归档载体到 `资料立档` 再选；电子介质锁定「内网 + 无需处置」 |

- 路径规范：`出网\年度\项目\资料名称`（共用服务器路径时前加申请部门）；请先把资料放入该相对路径再申请。
- 电子介质明细：手工录入；`选择父目录…` / `选择文件…` / `重新扫描` / `清空明细` / `查看明细…` 用于 **审批后** 从离线介质补录。
- 申请必填：`申请说明 *`、`申请人 *`、`部门 *`、`日期 *`；`附有证明材料` 选是须填名称。
- 按钮：`保存草稿`、`提交申请`、`打印申请`（年度资料出网申请审批单）。

### 出网审批（资料室）

菜单：`出网审批`。`打开办理`：

1. 审批通过前可补录 `服务器路径`；具体路径自动更新。
2. `审批通过` → **补录电子介质目录与数据量**（从离线介质 `选择父目录…` 扫描，数据量自动计算可微调）→ `确认实物交接`。
3. 签字节点与入网相同：部门负责人、生产管理科、资料室负责人、分管领导 + 移交人、资料员；打印单「分管领导」栏可能随目的地显示为分管生产或分管资料副院长。
4. 附件上传 `签批交接单`（及证明材料）→ `确认办结` → `打印交接单`。
5. 目的地为 `资料室存档` 的，办结生成建档草稿（在 `建档申请` 列表继续补全）；跨域过程在 `跨域流转台账` 查看。

### 在网数据处置（资料室）

菜单：`在网数据处置`。无部门申请侧；新增、提交、审批、办结均资料室。列表：`新增处置`、`打开处置`、`撤回作废`；另有 `查询台账`、`查看详情`、`查询单据`。

1. 候选区 `刷新候选`（在网台账按来源/状态/服务器路径/存储区/关键字筛选）→ `查看详情` → 勾选后 `加入明细`。
2. `批量原因` / `批量方式` + `赋值` 批量写入（也可逐行改）：处置原因 `到期清理`/`中间成果删除`/`软件卸载`/`安全销毁`/`其他`；处置方式 `服务器删除`/`台账注销`/`其他`。
3. 原因或方式为 `其他` 时申请说明必填。
4. 按钮：`保存草稿` → `提交` → `打印签批单`（在网数据处置签批单）→ `审批通过`（自动填 `资料室负责人`、`分管资料副院长` 姓名与日期，可改）→ `确认可上传` → 上传 `签批单` → `办结`。
5. 办结前不要只在服务器上删目录而不走本单；本流程无低格留盘、无撤柜勾选。

## 历史存档

菜单：`历史存档资料管理`。与年度立档事实分开，按盒号管理，每类资料按「存档数据表」存放。

### 地形图图件 / 航摄胶片像片 / 其他资料

三页操作一致，工具栏：`导入Excel表`（仅资料室）、`浏览数据`（`分页浏览` / `全局浏览`，分页含首页/上一页/下一页/末页与每页条数）、`编辑`、`检索`、`重置`、`含已离库` 勾选、`导出`、`删除当前行`、`删除表`。

**检索条件（按页不同）：**

| 页面 | 检索范围 |
| --- | --- |
| 地形图图件 | 盒号、比例尺、图号、当前图号、图名、日期、坐标系、高程基准、区域、备注 |
| 航摄胶片、像片 | 盒号、测区、比例尺、航摄日期、盒内物品、规格、登记人、备注 |
| 其他资料 | 序号、资料分类、年度、资料内容、盒号、规格、登记人、备注 |

**编辑字段（带 * 必填）：**

- 地形图：档案盒编号 *、比例尺 *、图号（当前图号系统换算、只读）、图名 *、幅数、档案盒规格、成图日期、调绘日期、坐标系统、高程基准、涉及省市县、备注。
- 航片：档案盒编号 *、测区名称 *、比例尺、航摄日期、相片张数、档案盒内物品、档案盒规格、备注。
- 其他：档案盒编号 *、资料内容 *、序号、资料分类、起始年度、截止年度、档案盒规格、备注。

**Excel 导入：** 选文件 → 选工作表 → 按中文表头映射（缺表头会提示缺少的列）→ 目标表已存在时选 `追加导入` / `重新建表` → 进度完成后提示导入条数与当前图号换算结果。

**图号换算支持的写法**（按比例尺自动换算为现行图号，无法识别时当前图号留空并在导入汇总中提示）：

- 现行国标：`J50G048010`（1:100 万图号 + 比例尺代码 + 行列号）。
- 旧式分段：`J-50-62-58`、`10-50-62-(24)`、`H-48-12-A-1-(3)` 等（1:10 万内 8×8 编 1–64；多幅可用 `、` 分隔）。
- 老图号（1:20 万图幅基准）：`4513-250` 型——前两位为 1:100 万图幅档案代码（当前仅收录 `45`→J-50），中间两位为该图幅内 1:20 万图幅序号（1–36），短横线后为 1:1 万图幅在该 1:20 万图幅内的序号（1–256，自西北角起行列连续编号）。仅对 1:1 万比例尺生效；未收录前缀留空提示，不会错换。

> 权限：导入、编辑、删除仅资料室办理账号（提示「仅资料室资料管理员可录入或编辑历史存档资料。」）；其他部门仅浏览、检索、导出。默认不显示已离库，勾 `含已离库` 才看；已离库记录只读、不能再改盒号。历史盒落入 `历史资料专用档口` 或 `混用档口`；Excel 导入时未设置且无年度占用的档口自动同步为历史专用，已占用的改为混用。

### 资料离库处置（历史）

仅资料室。列表：`新增处置`、`打开处置`、`撤回作废`、`查询盒`、`查询单据`。单号前缀 `史离-处`。

**硬规则：一单仅一类资料、一种处置方式；混放盒须整组纳入（勾选任一混放盒，系统自动带出关联盒）或整组移除；跨类同盒须先拆盒。**

1. 基本信息：`资料类别`（地形图图件 / 航摄胶片、像片 / 其他资料，选定后不可改）；`处置方式`：`离库销毁` / `离库转交`（须填转交对象）/ `其他`（须填说明）；`申请说明`。
2. 候选区（在柜档案盒，按资料类别/柜体/关键字筛选）：`刷新候选`、`加入明细`、`全部加入明细`、`清空明细`。
3. 审核审批：`资料室负责人`、`分管资料副院长`；`审批通过` 自动填姓名与日期，可改。
4. 七态按钮：保存草稿 → 提交 → 打印签批单（历史存档资料离库处置签批单）→ 审批通过 → 确认可上传 → 上传附件 → 办结。
5. 附件：`签批单` 必传；`离库销毁` 还须 `处置资料照片`；`其他附件` 可选。
6. 办结确认：「对应档案盒已从档案柜撤出实物。」三种处置方式都须确认实物撤柜；办结后台账标 `已离库` 并撤盒，台账行保留备查。

## 硬盘与光盘

菜单：`介质管理` → `硬盘` / `光盘`。部门只发起硬盘出库/归还；盘库、离库、改档口是资料室职责。

**介质状态速查：** `在库(空盘)`、`在库(资料)`、`在库(损坏)`、`在库(盘失)`、`在库(拟销)`、`出库(临时)`、`出库(长期)`、`出库(永久)`、`出库(挂失)`、`离库(处置)`；属性：`空白介质` / `资料载体`。

### 硬盘概览

`概览` 页看 KPI 并下钻：库存结构（介质总数、在库空白、资料在库、损坏在库、盘失、拟销）；出库/归还积压（待审批、待实物交接、待上传签批、待办结、逾期需归还）；专项（征用锁占用、处置进行中、盘库草稿）；台账质量（缺台账、在库未登记位置、出库未明确保管）。点卡片直接跳到对应台账/审批列表。

### 硬盘初始登记（资料室）

菜单：`初始登记`（库内硬盘物理参数台账表）。按钮：`批量式登记`（Excel 覆盖/追加导入，完成后自动为无位置空盘按空白专用档口入位）、`交互式登记`（弹窗单盘录入）、`硬盘参数修正`、`注销所选硬盘`、`查询`、`导出台账`、`刷新列表`。

交互式登记弹窗字段：硬盘编号 *（`自动生成`）、序列号 *（`读取本机` 选本机物理盘，系统盘与虚拟磁盘不可选）、硬盘类型 *、品牌 *、容量 *、接口类型 *、出厂日期 *、登记方式、`存放档口（空白硬盘）`（`推荐档口` + `档口快照`，按空白专用档口容量 10 盘/档口推荐）、备注。

> 此处只维护基础参数；介质状态由硬盘台账统一维护。空白盘落入 `空白硬盘专用档口`（无档内序号）。

### 硬盘出库申请 / 出库审批

菜单：`出库申请`（部门）、`出库审批`（资料室）。

**申请类型（三选一）：**

| 类型 | 归还期限 |
| --- | --- |
| `出库(临时)申请` | 约 1 个月，可填不晚于期限的预计归还日期 |
| `出库(长期)申请` | 不设期限 |
| `出库(永久)申请` | 另有他用、无需归还 |

- 一次最多关联 5 块硬盘，每块硬盘生成一份申请单，归还时可分别办理。
- 审批页办理：`申请->查看`、`申请->审批`、`强制作废`。录入 `审核人 *`（默认申请人部门负责人）、`审批人 *`（默认资料室负责人）、审批意见；交接须填办理交接人（申请人、资料管理员）与日期。
- 五步：`审批通过` → `确认实物交接` → `上传签批交接单`（或高影仪直拍）→ `确认办结` → `打印交接单`。征用库内空盘会写征用锁，锁定期禁止并行占用。

### 硬盘归还申请 / 审批入库

菜单：`归还申请`（登记单）、`审批入库`（资料室）。待归还介质列表 `发起归还`。

**登记类型 \*（三选一）与档口：**

| 类型 | 归位 | 特殊要求 |
| --- | --- | --- |
| `正常归还` | 空白硬盘专用档口 | 须选 `查验结果`、`格式化确认`（已格式化/未格式化/不适用） |
| `损坏归还` | 损坏硬盘专用档口 | 须填 `特殊情况说明 *` 并打印签批交接单 |
| `挂失登记` | 无需归位 | 同上 |

- 非正常归还（损坏/挂失）：弹「非正常归还情况」面板填具体情况说明；纸质签批还须归还人、申请人所属部门负责人、资料室负责人与资料室经办人签字。
- 按钮：`推荐档口`、`档口快照`、`保存草稿`、`提交申请`、`打印签批交接单`、`撤回作废`；审批侧 `审批通过`、`确认实物交接`、上传签批、`确认办结`、`打印交接单`、`强制作废`。

### 硬盘盘库登记（资料室）

菜单：`盘库登记`。仅 `在库(空盘)`、`在库(损坏)` 可选。

- 登记类型：`损坏登记`（为每块盘指定损坏硬盘专用档口，行内 `推荐` / `预览`；办结核验容量 10 盒/档口）/ `盘失登记`（无需归位，办结清空存放位置、写 `在库(盘失)`）。
- 候选 `筛选` → `加入 →` / `← 移除` → 填登记说明 → `保存草稿` / `确认登记办结`（即时写台账，无需审批）/ `撤回作废`。
- 日常损坏/盘失走本页；正式离库走下一菜单。

### 硬盘离库处置（资料室）

菜单：`离库处置`。候选：`在库(空盘)`、`在库(损坏)`、`在库(盘失)`、`在库(拟销)` 且 **未挂在用资料袋**；已挂资料袋的走「电子资料离库处置」。

- 移入后按状态自动带出离库原因（空盘→淘汰、损坏→损坏、盘失→盘失、拟销→拟销）；处置方式：`离库销毁` / `退还办公室` / `库内注销` / `其他`；勾选后可批量 `赋值`。
- 提交后写征用锁。流程：`保存草稿` → `提交` → `打印签批单` → `审批通过`（记当前办理人）→ `确认可上传` → 上传 `签批单` 与 `硬盘照片` → `办结`。
- 打印「资料室审批」外，另有资料室负责人、资料室分管领导签字栏（线下签；办结后重打按办结日预填）。

### 硬盘台账

菜单：`硬盘台账`。上半部介质台账（状态、属性、当前位置、持有人/保管单位、是否要求归还、征用标记），右侧看初始登记信息与征用锁记录，下半部 `历史流转记录`（登记、出库、归还、挂失、盘库、位置调整、档内序号变更等流水）。筛选举含 `征用锁:`（年度资料登记、硬盘借出申请、资料出库征用、出网征用、盘库、离库处置等来源）。

### 光盘

菜单：`光盘` → `概览`、`流转台账`。

- 光盘随电子立档自动产生（登记方式「资料存档登记」），**不管理空白盘**、无独立借还菜单。
- 状态：`在库(资料)`、`出库(临时)`、`在库(损坏)`、`在库(盘失)`、`在库(拟销)`、`出库(销毁)`。
- 办理走年度资料出库/归还/盘库/离库：拟销或损坏离库后常为 `出库(销毁)`；盘失走 `库内注销`。光盘不能单独出库，也不能低格留盘（那是硬盘的能力）。
- 概览 KPI 下钻台账；流转台账可按光盘编号、业务单号、流转类型查流水。

## 系统设置

菜单：`系统设置`。除「个人设置」人人可用外：系统管理员可进用户/部门/角色、高级数据、业务逻辑、操作日志；`服务器路径设置` 仅网管负责人（提示「仅网管负责人可维护服务器路径设置。」）。资料办理人不要用系统管理员或网管账号点业务按钮。

### 用户、部门、角色怎么开

顺序：**先部门、再角色、再用户**。用户上的「所属部门」「用户角色」必须与部门表、角色表名称完全一致（不要多空格、不要近义名）。

1. `部门设置`：`新增部门`、`编辑部门`、`删除选中`、`刷新列表`。资料室办理账号依赖的部门名必须是 **资料室** 三个字。
2. `角色设置`：业务角色至少包括 `Administrator`（或「管理员」）、`部门资料管理员`、`网管负责人`。「部门负责人」「分管资料副院长」等角色主要用于单据签字栏人选参考，单独配这些角色登录并不能获得申请或审批菜单。
3. `用户管理`：`新增用户`、`编辑选中`、`删除选中`、`刷新列表`。字段：登录账号 *、真实姓名 *、所属部门、用户角色、登录密码（≥8 位且不能等于登录账号；编辑留空=不改）。重置后对方下次登录必须改密。系统默认管理员不能删除。

> 首次部署空库自动创建账号 `admin`（初始口令 123456，首次登录强制改密）。判定规则只认账号上的部门、角色字段，不按姓名推断。一人多岗开两个账号，不要把系统管理员和资料办理角色混在一个账号上。

### 业务权限：先看部门，再看角色

| 业务身份 | 所属部门 | 用户角色 | 用来做什么 |
| --- | --- | --- | --- |
| 部门申请经办 | 任一业务科室，**不能是「资料室」** | `部门资料管理员` | 只发起申请：建档、借出、归还、入网、出网、硬盘出库/归还 |
| 资料室办理 | **必须是「资料室」** | **必须是「部门资料管理员」** | 审批、交接、立档、直办、迁档、盘库、离库、档案柜登记、历史录入、硬盘全流程 |
| 网管负责人 | 任意 | **必须是「网管负责人」** | **仅** `服务器路径设置` |
| 系统运维 | 任意 | `Administrator` 或 `管理员` | 用户/部门/角色、高级数据、业务逻辑、操作日志；不含服务器路径、不办业务 |

**不要这样开：**

- 部门「资料室」+ 角色「部门负责人」→ 既不能申请，办理菜单也多灰。资料室负责人签字由办理人在单据上填写姓名即可。
- 生产科室 + `部门资料管理员`，却指望点「申请审批」「资料立档」→ 菜单灰色。
- 部门「资料室」+ 自造角色「资料室资料管理员」「资料室管理员」→ 部分能办，但 `资料立档、直办立档、立档/迁档/流转台账、硬盘初始登记与出库审批/盘库/离库` 仍会灰。请统一用「部门资料管理员」。
- `Administrator` 去立档、审批、改服务器路径 → 均无权限。
- 网管负责人账号提交出入网申请 → 不能；单据里只是选用其维护的路径。

### 按菜单：谁能进、谁能改

灰色 = 当前账号无权进入；能打开页面不等于能改数据。

**所有登录用户通常可：** `帮助` → `操作手册`；`个人设置`；项目信息设置（浏览检索）；三种资料检索与检索池（一般人只管自己建的池）；历史三页（浏览、检索、导出）；`档案柜检索`（开柜查看）；硬盘/光盘 `概览` 与台账；`高级数据管理`（浏览模式：仅浏览/检索/导出数据表）。

**部门申请经办可点：** 建档申请、借出申请、归还申请、入网申请、出网申请、硬盘出库申请、硬盘归还申请。列表里一般只办本账号的单；保存草稿、提交、撤回都是申请人侧。

**资料室办理可点：** 申请审批、资料立档、两个直办立档、立档台账、迁档台账、流转台账、跨域流转台账；审批出库、审批入库；模拟/电子迁档；模拟/电子盘库；模拟/电子资料离库、历史离库处置；入网审批、出网审批、在网数据处置；档案柜登记；硬盘初始登记、出库审批、审批入库、盘库登记、离库处置、硬盘台账；项目与历史台账的导入编辑删除；开柜改用途、迁档、摆放。

**网管负责人可点：** 仅 `服务器路径设置`（新增、编辑、删除）。

**系统运维可点：** 用户管理、部门设置、角色设置、权限设置、高级数据管理（全量维护）、逾期设置、数据库操作日志。

### 签字角色 ≠ 登录权限

角色表里的「部门负责人」「分管生产副院长」「分管资料副院长」「院长」对应打印单、审批栏上的**职务名称**，由资料室办理人在审批页填写姓名（或回填默认），不要求领导本人登录点按钮。「网管负责人」是登录后维护服务器路径的业务角色，须单独开账号，不是签字栏职务。给领导单独开账号且不兼办申请时，角色不要选「部门资料管理员」。

### 服务器路径设置（网管负责人）

维护项：`部门 *`（含公用）、`路径名称 *`、`物理地址 *`、`权限 *`、`容量(TB) *`。改物理地址前确认没有进行中的入网/出网单还在用旧地址。角色名必须与角色表完全一致：`网管负责人`。

### 逾期设置（系统管理员）

`申请单逾期设置`：`当天` / `7天` / `30天`，控制资料室对未审批申请单执行强制作废的最早时限。改完影响未办结单据提醒，不要频繁改。`保存设置` / `恢复默认`。

### 权限设置（系统管理员）

只读查阅页：上半部分列出角色表，下半部分按业务分组展示「系统管理员 / 资料室办理 / 部门申请 / 网管负责人 / 其他用户」可用的菜单矩阵。权限由「部门 + 角色」业务规则判定，不能在此页直接改；调整权限请到 `用户管理` 修改账号的角色，或在 `角色设置` 维护角色名称。

### 个人设置（所有用户）

- `修改密码`：当前密码、新密码、确认新密码；新密码 ≥8 位且不能与登录账号相同。
- 待办偏好：`登录后显示待办弹窗`、`主界面显示待办角标`、`点击"知道了"后将当前待办标记为已读`、`待办刷新频率(秒)`（5~3600，默认 15）、`待办展示条数`（1~200，默认 20）。`保存设置` / `恢复默认`。

### 高级数据管理（全员可浏览，危险区）

- 数据浏览对全员开放：选表、分页查看、检索、`导出到 Excel`。
- 资料室资料管理员（受限模式）：另可 `备份当前库`；删除、清空、还原及字典维护仍不可用。
- 系统管理员（全量）：
  - 数据字典维护（SchemaDictionary.yaml）：`同步 EF 模型到字典`、`导出 DB 显示名到字典`、`从字典重置 DB 显示名`、`保存显示名并写回字典`。
  - `从备份还原`：共享库先确认其他终端已退出；还原覆盖当前库且不可撤销，完成后程序退出须重开。覆盖安装只替换程序文件，**不要覆盖 DocMgr.db**。
  - 删除记录 / 清空表为高危操作，双重确认。

### 数据库操作日志（系统管理员）

按时间、表名、操作（Added/Modified/Deleted）、关键字查增删改摘要，用于事后核对，不是办理入口。可 `停止记录` / `启动记录` / `清除所有日志`。
