# 资料室管理系统 — 覆盖安装与备份

程序版本见登录窗左侧、主窗口导航栏底部。发版只改程序文件，**不要覆盖业务数据库**。

## 数据库在哪

- 单机默认：程序目录下的 `DocMgr.db`（与 `DocMgr.exe` 同级）。
- 局域网共享：以 `appsettings.json` 中 `Database:Path` 为准（示例见 `appsettings.lan.example.json`）。

## 覆盖安装（升级）步骤

1. 让所有终端退出本程序。
2. 在「系统设置 → 高级数据管理」点 **备份当前库**，把备份放到安装目录以外（U 盘或文档文件夹）。
3. **只替换** `DocMgr.exe`、依赖 dll、以及需要更新的配置模板。  
   **不要**用新包里的空库覆盖正在用的 `DocMgr.db`、`DocMgr.db-wal`、`DocMgr.db-shm`。
4. 启动新版本。若有数据库结构升级，程序会在迁移前自动再备一份（同目录 `DocMgr.pre-migrate-时间.db`，最多保留 3 份）。
5. 登录确认待办与业务数据仍在。

## 不要这样做

- 把整个安装文件夹连同 `DocMgr.db` 一起覆盖（会换成空库或旧测试库）。
- 升级过程中其他电脑仍开着客户端写共享库。
- 用资源管理器直接复制正在使用的 `DocMgr.db`（可能拷到不完整的 WAL）。请用程序内备份。

## 还原

「高级数据管理 → 从备份还原」会覆盖当前库，完成后程序退出，需重新打开。共享库还原前必须所有终端已退出。

## 配置

- 新版本若带了新的 `appsettings.json`，不要直接覆盖已改过路径的那份；只把需要的新项手工合并进去。
