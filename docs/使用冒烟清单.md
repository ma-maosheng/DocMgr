# 使用期冒烟清单

发现问题时记下：菜单路径、单号、角色、期望与实际。修一处提交一处，不做结构改造。

打印签批单：办结前交接双方签字栏必须留白；已办结重打才预填。

数据库：业务库为 SQL Server（默认 `DocMgr`）。升级前在「高级数据管理」备份 `.bak`；覆盖安装只换程序，勿冲掉 `appsettings.json` 连接串。

| --- | --- | --- | --- |
| 1 | 登录后待办弹窗、角标 | 登录 → 主窗口待办 | |

| 3b | 存量光盘直办：扫描资料所属目录，确认后光盘编号与介质袋编号相同 | 年度资料 → 建档与立档 → 存量光盘直办 | |
